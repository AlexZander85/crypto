# ПРОЕКТ: Слой «Новости как учебный материал» — КриптоНавигатор
Версия 1.0 · Дата: 24.08.2026 · Отдельный модуль к слою «Живой рынок» (`PROJECT_LIVE_MARKET_COACH.md`)
Статус: реализуется ПОСЛЕ завершения агентом основного слоя Живого рынка (тот же воркер, тот же каркас карточек).

---

## 0. Суть одной фразой
Лента реальных крипто-новостей прямо в приложении — и **наставник, который разбирает каждую новость**: о чём она на самом деле, на какую часть рынка давит механически, и чего она сознательно не говорит. Не сигналы, не прогнозы — обучение чтению информационного потока.

## 1. ЯЗЫК ЛЕНТЫ (принципиально)
Пользователь читает новости только на языке своего интерфейса.
- **Русская локаль:** ForkLog, BeInCrypto RU и другие активные русскоязычные крипто-RSS;
- Переключатель «показывать мировые»: заголовки CoinDesk/Decrypt с **автопереводом** через Cloudflare Workers AI (бесплатная квота; один заголовок переводится один раз, кэш 24 ч), пометка «авто-перевод», ссылка на оригинал;
- Регуляторные первоисточники (SEC, ESMA) — всегда в ленте на языке оригинала: слишком важны, чтобы терять; карточка наставника объясняет их на языке пользователя;
- Карточки наставника ВСЕГДА на языке интерфейса — это наши тексты из контент-паков, а не переводы чужих статей.

## 2. ИСТОЧНИКИ И ДОСТАВКА
RSS-ленты (легальная синдикация): EN — CoinDesk, Cointelegraph, Decrypt, Bitcoin Magazine, NewsBTC, CryptoSlate; RU — ForkLog, BeInCrypto RU; регуляторика — SEC press RSS, ESMA news.
Через тот же Worker: `GET /api/live/news?locale=ru|en&limit=30&world=on|off` → нормализованный JSON {title, source, url, published_at, lang}, кэш 15 мин, атрибуция источника обязательна.

## 3. КАК РАЗБОР НОВОСТЕЙ РАБОТАЕТ БЕЗ НЕЙРОСЕТЕЙ (алгоритм для реализации)

Наставник не «понимает» текст. Он делает три детерминированные вещи:

### 3.1 Источник = первый классификатор
Мы сами выбираем каналы с известным профилем: пресс-релизы SEC — это всегда регуляторика; mempool.space — всегда сеть; профильные СМИ — общий поток. Плюс у RSS есть рубрики (categories) — используем их как первичную подсказку. Категория известна ещё до чтения текста.

### 3.2 Словари маркеров по заголовку и первому абзацу
Для каждого из 7 типов — словарь триггеров с весами:
- Регуляторное: SEC, комиссия, иск, штраф, запрет, лицензия, закон, MiCA, суд…
- Безопасность: взлом, эксплойт, украдено, мост, утечка, фишинг + суммы («$X млн»)
- Макро: ставка, инфляция, ФРС, индекс потребительских цен, доллар укрепился…
- Технологическое: хардфорк, апгрейд, обновление сети, тестнет запущен
- Рынок капитала: ETF, листинг, IPO, приток/отток средств
- Хайп/маркетинг: партнёрство, коллаборация, интеграция (без имён!), «миллионы пользователей» без аудита
- Скам-маркеры: гарантированный доход, фиксированный процент, «по требованию регулятора» без реквизитов, CAPS-заголовки, отсутствие дат и цифр
Подсчёт: сумма весов совпадений → тип с максимальным баллом становится «подсказкой категории». Точность не идеальна — так и задумано: спорные случаи это корм для режима «Угадай тип».

### 3.3 Обучение на подтверждениях пользователей (без нейросетей)
Режим «Угадай тип»: пользователь называет категорию до раскрытия → его ответ сохраняется вместе со словами заголовка. Простая частотная таблица «слово → тип» пополняется от каждого подтверждения. Со временем система классифицирует лучше — на данных своих же пользователей. Никакой магии: обычный наивный счётчик Байеса.

### 3.4 Карточка наставника собирается из ЗАГОТОВОК по типу
«Понимание» новости = библиотека из 7 шаблонов карточек, написанных человеком заранее:
- Тип «регуляторное» → МЕХАНИКА: «правила меняют доступ участников и издержки compliance — цена реагирует прежде всего на неопределённость правил, а не на сам факт»; ЧЕГО НЕ ГОВОРИТ: «сроки вступления, детали исполнения, реакция других регуляторов»;
- Тип «безопасность» → МЕХАНИКА: «прямые потери конкретного протокола + рост требований к доходности за риск хранения на площадках»; ЧЕГО НЕ ГОВОРИТ: масштаб потерь, был ли страховой фонд, повторится ли эксплойт.
ФАКТ берётся из самой новости (подзаголовок RSS / первое предложение), числа — регулярками ($X млн, проценты, даты) вставляются в поля карточки. Поэтому фактов «из воздуха» не бывает: всё, что говорит наставник, — либо текст новости, либо заранее написанная человеком заготовка категории.

### 3.5 «История знает ответ» работает вообще без разбора
Архив учебных кейсов создаётся один раз вручную (10–20 знаковых событий курса: FTX, одобрение ETF, халвинг, деpeg USDC…): новость + дата + фактическое движение рынка после неё (цены подтягиваются историческим API автоматически). Пользователь предсказывает с уверенностью → раскрытие факта → Brier-калибровка. Вывод формулирует приложение: даже зная новость, направление угадать нельзя — поэтому управляют размером позиции, а не предсказаниями.

## 4. ТАКСОНОМИЯ (7 типов) — см. §3.2 список
Регуляторное · Безопасность · Макро · Технологическое · Рынок капитала · Хайп/маркетинг · Скам-маркеры.

## 5. УПРАЖНЕНИЯ (три режима)
1. **Угадай тип** — категория до раскрытия; точность по типам = карта твоих слепых зон;
2. **История знает ответ** — архивный кейс → прогноз с уверенностью → факт → калибровка;
3. **Анти-FUD / анти-хайп** — два заголовка разных источников об одном событии: найди эмоциональные маркеры и отсутствующие цифры (связки: 0.18, Детектив недели, урок П6).

## 6. ГЕИТИНГ И ЗАЩИТА ВНИМАНИЯ
- Открытие после уроков 2.1–2.2; анти-FUD после 0.18;
- Таймер чтения: 10 минут ленты → карточка П6 «тяга к движению растёт — закрой вкладку или запись в журнал»;
- Лента живёт отдельной вкладкой внутри «Живого рынка», никогда — бейджами поверх стакана;
- Язык карточек = язык интерфейса независимо от языка источника; мировые заголовки в русской ленте помечены как авто-перевод.

## 7. ГРАНИЦЫ (этика)
Никаких направлений сделки в любом тексте слоя. Новости учат анатомии информации, а не предсказаниям. Дисклеймер на каждом экране.

## 8. ПРИЁМКА (для агента)
1. Лента собирается из указанных RSS через Worker, нормализована, атрибуция на каждой карточке;
2. Русская локаль показывает только русскоязычные источники при world=off; world=on добавляет переведённые заголовки с пометкой;
3. Разметка типа работает на подготовленных примерах всех 7 категорий (тестовый набор ≥35 заголовков, точность ≥70%);
4. Все три упражнения проходимы; ответы пишутся в cn_news_stats; калибровка считается;
5. Таймер внимания срабатывает на 10-й минуте чтения;
6. Ни одна строка слоя не содержит торговых рекомендаций (grep-проверка по списку запрещённых формулировок);
7. Офлайн/отказ источников: баннер возраста снимка, приложение не падает.

## Тарифная принадлежность
Слой входит в тарифы «Про» и «Макс» (см. PROJECT_SAAS_CLOUDFLARE.md §14.1). В демо и «Лайт» не активируется — учебные режимы данных доступны всем, живые новости становятся первым аргументом апгрейда после полного прохождения курса.
