# Три урока: 4.5, 4.7 (+БОН-L) и ВК4

Сначала — три решения по структуре, потом сами тексты. Формат текстов — тот же, что в курсе (лид → база → Подробнее → Глубже → код → Аналогия → Числа → Важно → таблица → проверка → Итог → Термины → Практика → Самопроверка → Ресурсы), плюс шапка «что нужно знать / что будешь уметь» из части 2 аудита. Герой везде — Алексей, счёт $1000 виртуальных, цель — микро-лайв 100–200 тыс. ₽.

## Решения по структуре

**1. Урок 4.5 и FT-19b/FT-19c.** Пересечение есть только с **FT-19b** («сверка dry-run с бэктестом по цифрам»); FT-19c — это переезд на VPS, к ED он не относится. **Сливать не надо**, но нужно жёстко разделить роли:

| | 4.5 (Фаза 4, до Freqtrade) | FT-19b (внутри Академии) |
|---|---|---|
| Что делает | Вводит понятие, метод сверки, нормативы 10/25, три калибровки, журнал позывов | Показывает **как** это сделать в Freqtrade: `--export trades`, экспорт сделок dry-run, скрипт сверки |
| Чего НЕ содержит | Команд Freqtrade | Повторного объяснения нормативов — только ссылка «пороги из 4.5» |
| Симулятор | «Калькулятор ED» + «Сверка двух таблиц» (№32 из части 3) на учебных данных | Тот же компонент «Сверка двух таблиц», но с загрузкой своих файлов |

Побочные правки после переписывания 4.5: в 5.1 «расхождение < 10–15 %» → «< 10 %, серая зона до 25 %»; таблица 5.1 «6–8 недель» и FT-20 «4–8 недель» → единое «8 недель, но не меньше 50 сделок»; экзамен в.23 «15–20 %» → 10/25; абзац «Пятый столб — честные задержки» из старого 4.5 удаляется — его содержание вошло в раздел про источники расхождения.
