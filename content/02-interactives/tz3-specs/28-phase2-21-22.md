# Спецификации интерактивов Фазы 2 · уроки 2.1 и 2.2

Документ для агента-реализатора. Два интерактива: **SIM-2.1-QUEUE «Очередь в кафе»** и **ANIM-2.2-LATENCY «Гонка задержек»**. Сначала — общие требования (они одинаковы для обоих), затем детальные спеки.

---

## 0. Общие требования к обоим интерактивам

### 0.1. Язык и терминология
- Весь интерфейс, подписи, тултипы, сообщения об ошибках — **только по-русски**. Английский термин допустим лишь в скобках внутри тултипа («Ткни в непонятное»).
- Обязательные русские замены: `latency` → «задержка»; `bps` → «б.п.» с тултипом «базисный пункт = 0,01 %»; `Fear & Greed` → «индекс страха и жадности»; `win rate` → «доля прибыльных»; `drawdown` → «просадка»; `ETF` → «биржевой фонд (ETF)» с тултипом; `MTProto` → «протокол Телеграма» с тултипом; `taker/maker` → «заявка по рынку / заявка в очереди» с тултипом.
- Любой термин из блока «Термины урока» — кликабелен, ведёт в глоссарий приложения (единый словарь). Список токенов для словаря приведён в конце каждой спеки.

### 0.2. Числа
- Все числа, которые ученик видит в интерактиве, должны либо **совпадать с текстом урока**, либо быть явно помечены плашкой «учебная модель» (серый бейдж рядом с графиком). Нельзя показывать «реальные исторические» данные — только сгенерированные с фиксированным сидом, откалиброванные под числа урока.
- Генератор случайных чисел — детерминированный (`mulberry32` или аналог), сид фиксирован по умолчанию, кнопка «Другая выборка» меняет сид (и показывает новый номер сида). Один и тот же сид → пиксельно тот же результат на любом устройстве.

### 0.3. Методический паттерн «прогноз до раскрытия»
- В обоих интерактивах есть **обязательный вопрос-прогноз до показа результата**. Пока ученик не выбрал вариант, ключевая панель размыта (`blur`) и не интерактивна. Ответ ученика сохраняется в телеметрии; после раскрытия показывается «Ты ожидал: … / На деле: …».

### 0.4. Технические рамки
- Компонент изолирован (React/Vue/Svelte — по стеку приложения), принимает `props` конфигурации (см. JSON в каждой спеке), не делает сетевых запросов.
- Рендер: SVG или Canvas; анимации через `requestAnimationFrame`, с уважением `prefers-reduced-motion` (в этом режиме анимации заменяются мгновенными переходами + пошаговыми кнопками «Далее»).
- Адаптив: ширина от 360 px. На узких экранах панели складываются вертикально, ползунки не уже 44 px по высоте касания.
- Доступность: все ползунки — `<input type="range">` с `aria-valuetext` на русском («индекс 90 — экстремальная жадность»); все состояния дублируются текстом, а не только цветом; цвета страха/жадности проверены на контраст ≥ 4,5:1.
- Производительность: любое изменение ползунка пересчитывает модель ≤ 5 мс; выборки для графиков (до 2000 точек) — предрасчёт при монтировании.

### 0.5. Телеметрия (события в аналитику приложения)
Единый формат `{ interactive_id, lesson_id, event, payload, ts }`. Обязательные события: `opened`, `prediction_made {choice}`, `reveal`, `slider_changed {name, value}` (троттлинг 500 мс), `mode_switched {mode}`, `scenario_finished {id, outcome}`, `final_check {choice, correct}`, `completed {duration_s}`.

### 0.6. Критерий «интерактив пройден»
Интерактив считается пройденным (зелёная галочка в прогрессе урока), когда ученик (а) сделал прогноз, (б) побывал во всех обязательных режимах, (в) правильно ответил на финальную проверку (допускается вторая попытка с объяснением ошибки).

## 1. SIM-2.1-QUEUE · «Очередь в кафе»

### 1.1. Паспорт
| Поле | Значение |
|---|---|
| ID | `SIM-2.1-QUEUE` |
| Урок | 2.1 (Урок 33) «Сентимент рынка» |
| Тип | СИМ (симуляция) + элемент ИГР (прогноз до раскрытия, финальная проверка) |
| Заблуждение | **«Жадность = покупай»** (и зеркальное: «жадность = сразу шорти») |
| Место в уроке | Сразу после блока «Аналогия: очередь в кафе», перед блоком «Числа». Существующий «Тренажёр: как читать индекс страха и жадности» остаётся — он учит *читать шкалу*, наш интерактив учит *почему сигнал контрарный* и *почему он не триггер* |
| Время | 6–8 минут |
| Связи | 0.13 (малая выборка), 1.9 / М43 (доверие к результату), М10 (зависимые наблюдения), 5.5 (стоп и просадка), П53 (серия без памяти) |
| Персонаж | Алексей, депозит 1000 $ — используется в шаге 3 |

### 1.2. Педагогические цели (что должен вынести ученик)
1. Индекс 0–100 — это **длина очереди**, а не качество кофе: он показывает, сколько участников *уже* купили, а значит — сколько *ещё могут* купить и сколько *могут* продать.
2. Поэтому сигнал **контрарный**: при экстремальной жадности покупателей не осталось, при экстремальном страхе продавцов не осталось.
3. Сигнал живёт **только в крайностях**; середина шкалы — шум.
4. Средняя доходность по зоне (+42 % при индексе < 15) — **средняя по зависимым дням с широким разбросом**, а не гарантия; внутри окна была просадка.
5. **Асимметрия**: страх разряжается за 1–3 дня, жадность растягивается на недели → «жадность» означает «не добавляй и готовься», а не «шорти по индексу».
6. После запуска биржевых фондов (2024+) сигнал ослаб: индекс — один из входов, а не самостоятельный триггер.

**Критерий освоения:** ученик правильно отвечает на две проверки — (1) при индексе 90 «сколько осталось покупателей» ≈ 10 и направление давления — вниз; (2) финальный вопрос «Индекс 88. Что делает системный трейдер?» → «не добавляет длинных позиций, использует индекс как фильтр, ждёт подтверждения ценой».

### 1.3. Структура: три шага + финальная проверка
Линейный степпер с возможностью вернуться назад: **① Очередь → ② Статистика зон → ③ Ловушка симметрии → ✔ Проверка**. Переход к следующему шагу разблокируется после выполнения условия шага (см. ниже).

### 1.4. Шаг ① «Очередь»: механика давления

#### Экран
```
┌──────────────────────────────────────────────────────────────┐
│ Индекс страха и жадности:  [0 ────●────────── 100]   = 62   │
│ зона: «нейтрально»                                          │
├────────────────────────┬─────────────────────────────────────┤
│  КАФЕ (SVG-сцена)      │  ПАНЕЛЬ ОЧЕРЕДИ                     │
│  ┌────────────┐        │  Уже внутри (купили):        62     │
│  │ ●●●●●●●●●● │ ○○○○   │  Ещё могут купить:           38     │
│  │ ●●●●●●●●●● │ ○○○○   │  Могут продать (выйти):      62     │
│  │ ●●●●●●●●●● │ ○○○    │                                     │
│  └────────────┘        │  Давление:  ◄───────●──►            │
│  100 участников:       │  «продавцы  · · ·  покупатели      │
│  ● внутри  ○ снаружи   │   кончились        кончились»      │
├────────────────────────┴─────────────────────────────────────┤
│  Цена (мини-график, 60 «дней»)     День: 0    Цена: 100,0   │
│  [ Пустить хорошую новость ]  [ Пустить плохую новость ]     │
│  [ Пустить случайную ×10 ]     [ Сбросить ]                  │
└──────────────────────────────────────────────────────────────┘
```

#### Модель
- `I` — индекс 0–100 (целое). Зоны: 0–14 «экстремальный страх», 15–34 «страх», 35–64 «нейтрально», 65–84 «жадность», 85–100 «экстремальная жадность». Цвет зоны и подпись под ползунком.
- Сцена: ровно 100 фигурок. `inside = I`, `outside = 100 − I`. При движении ползунка фигурки анимированно переходят через дверь (при `reduced-motion` — мгновенно).
- Панель: «Уже внутри» = `I`; «Ещё могут купить» = `100 − I`; «Могут продать» = `I`.
- Давление `P = (100 − I) − I = 100 − 2I`, шкала от −100 до +100; подпись: `P > 30` → «продавцов мало, покупателей много — цене проще идти вверх»; `|P| ≤ 30` → «баланс — индекс ничего не говорит»; `P < −30` → «покупателей мало, продавцов много — любая плохая новость обрушит цену».
- Новость: сила `s` ∈ {4, 8, 12} % (случайно, сид), знак задан кнопкой (или случайно 50/50 для «×10»).
  - Хорошая новость: `Δp = + s · (100 − I) / 100`
  - Плохая новость: `Δp = − s · (I / 100) · k_fear`, где `k_fear = 1,4` (страх резче)
  - Обновление индекса: `I ← clamp(I + 0,8 · Δp, 0, 100)`
  - Обновление цены: `price ← price · (1 + Δp/100)`
  - **Асимметрия во времени** (ключевой визуальный эффект): падение отрисовывается за `1–3` «дня» (быстрая анимация выхода толпы), рост — за `7–20` «дней» (медленный заход). Счётчик дней увеличивается соответственно. Подпись при плохой новости: «Толпа выбежала за 2 дня»; при хорошей: «Зал наполнялся 14 дней».
- Мини-график цены: 60-дневное окно, прокручивается.

#### Прогноз до раскрытия (обязательный)
При первом входе ползунок зафиксирован на `I = 90`, панель очереди размыта. Вопрос:
> «Индекс 90 — экстремальная жадность. Все говорят о росте. Что скорее всего дальше на горизонте недель?»
> ○ «Ещё рост — раз все покупают, значит, спрос сильный»
> ○ «Скорее вниз — покупать уже почти некому»
> ○ «Индекс ничего не говорит о направлении»

После выбора — раскрытие панели: «Ещё могут купить: 10. Могут продать: 90». Обратная связь по вариантам:
- Вариант 1: «Ты только что выбрал “жадность = покупай”. Посмотри на дверь: снаружи 10 человек. Кто будет покупать дальше?»
- Вариант 2: «Верно по механике. Но не спеши шортить — шаг ③ покажет, почему».
- Вариант 3: «В середине шкалы — да. На краю (90) очередь говорит очень много».

#### Условие перехода к шагу ②
Ученик пустил ≥ 5 новостей при `I ≥ 85` и ≥ 5 при `I ≤ 15` (подсказка-задание в шапке шага: «Проведи по 5 новостей на каждом краю шкалы»). Внизу шага после выполнения появляется сводка: «При индексе ≥ 85 средний исход новости: −X % · При индексе ≤ 15: +Y %» (считается по фактическим прогонам ученика).

### 1.5. Шаг ② «Статистика зон»: средняя ≠ гарантия

#### Экран
```
┌──────────────────────────────────────────────────────────────┐
│ Период:  (● 2020–2024)  (○ 2024+ после биржевых фондов)      │
│ Метрика: (● доходность за 90 дней) (○ худшая просадка в окне)│
├──────────────────────────────────────────────────────────────┤
│  СТОЛБЦЫ ПО ЗОНАМ (среднее ± 95% интервал)      [учебная     │
│                                                    модель]   │
│   +42%┃█                                                     │
│       ┃█  +9%                                                │
│     0 ┃█──█───▪───▪───────────                               │
│       ┃          ▪   ▪  −8%                                  │
│       ┃              █                                       │
│   0–14  15–34  35–64  65–84  85–100                          │
│   дней: 45 210 780 520 120                                   │
│   эпизодов: 6  19   61  38   11    ← считаем интервал по ним │
├──────────────────────────────────────────────────────────────┤
│  Клик по столбцу → «полоса исходов» выбранной зоны:          │
│  каждая точка — один день входа: ·· ·  ·······  · · ·         │
│  доля прибыльных 78% · лучший +112% · худший −31% ·          │
│  средняя просадка внутри окна −13%                           │
└──────────────────────────────────────────────────────────────┘
```

#### Модель данных (генератор, сид `20200101`)
Наблюдение = день входа в зоне. Для каждого дня генерируется:
- `ret90` — доходность за 90 дней, смесь двух нормальных: с вероятностью `p_plus` — `N(μ+, σ+)`, иначе `N(μ−, σ−)`; клип к диапазону [−60; +200].
- `dd90` — худшая просадка в окне: `dd90 = min(0, ret90) − |N(0, σ_dd)|`, клип к [−70; 0].
- Дни группируются в **эпизоды** (последовательные дни в одной зоне): длина эпизода ~ геометрическое распределение со средним `L_zone`. Внутри эпизода исходы коррелированы: `ret90_day = 0,7·ret90_episode + 0,3·ret90_iid` (иначе интервал будет нечестно узким — это и есть урок М10).

| Зона | дней | ср. длина эпизода | p_plus | μ+ / σ+ | μ− / σ− | σ_dd | Целевое среднее ret90 | Целевая доля + | Целевая ср. просадка |
|---|---|---|---|---|---|---|---|---|---|
| 0–14 | 45 | 7 | 0,78 | 60 / 25 | −22 / 10 | 10 | **+42 %** | **78 %** | ≈ −13 % |
| 15–34 | 210 | 11 | 0,60 | 25 / 15 | −15 / 10 | 9 | ≈ +9 % | 60 % | ≈ −13 % |
| 35–64 | 780 | 13 | 0,52 | 16 / 14 | −14 / 12 | 8 | ≈ +2 % | 52 % | ≈ −13 % |
| 65–84 | 520 | 14 | 0,48 | 14 / 12 | −15 / 12 | 9 | ≈ −1 % | 48 % | ≈ −15 % |
| 85–100 | 120 | 11 | 0,40 | 10 / 8 | −20 / 10 | 8 | ≈ −8 % | 40 % | **≈ −18 %** |

Жирным — числа, которые обязаны совпасть с текстом урока (допуск ±2 п.п.; при генерации проверить юнит-тестом и при необходимости подстроить сид). Остальные — иллюстративные, помечены бейджем «учебная модель».

**Период «2024+ после биржевых фондов»** (сид `20240111`): все зоны — те же параметры, кроме крайних:
- 0–14: дней 18, эпизодов 2, `p_plus 0,58`, `μ+ 30 / 25`, `μ− −20 / 12` → среднее ≈ +9 %, интервал накрывает ноль.
- 85–100: дней 60, эпизодов 5, `p_plus 0,45`, `μ+ 12/10`, `μ− −14/10` → среднее ≈ −2 %.
- На графике поверх столбцов появляется полупрозрачная лента «Потоки биржевых фондов и макро» с подписью: «В 2024+ эти потоки часто перекрикивают настроение розницы. Индекс — один из входов, не триггер».

**Доверительный интервал:** `±1,96 · sd(ret90 по эпизодам) / √(n_эпизодов)`. Под столбцами две строки: «дней» и «эпизодов», тултип на «эпизодов»: «Соседние дни в одной зоне — почти одно и то же наблюдение. Честный интервал считаем по эпизодам, а не по дням (урок М10)».

#### Поведение
- Переключатель метрики меняет столбцы на «худшая просадка в окне» — зона 0–14 показывает ≈ −13 %: подпись «Даже покупая в экстремальном страхе, ты в среднем сначала сидел в −13 %. Индекс не ловит дно — он говорит, что дно близко».
- Средние зоны: если интервал накрывает ноль, столбец перекрашивается в серый, подпись «нет информации». Обязательная плашка над графиком: «Сигнал живёт только в крайностях».
- Клик по столбцу открывает полосу исходов (strip plot, до 780 точек, разрежать до 300 для отрисовки с сохранением экстремумов). Показывать 4 числа: доля прибыльных, лучший, худший, средняя просадка.
- Кнопка «Другая выборка» — новый сид → числа плавают в пределах интервалов; подпись: «Средняя по 6 эпизодам гуляет. Это не закон природы, а точечная оценка на конкретном окне» (цитата урока).

#### Условие перехода к шагу ③
Ученик переключил период на «2024+» и открыл полосу исходов хотя бы одной крайней зоны.

### 1.6. Шаг ③ «Ловушка симметрии»: почему «жадность» ≠ «шорти»

Два сценария на депозите Алексея (1000 $), проигрываются по кнопке «Запустить», 90 дней, скорость ×10 с паузой.

**Сценарий А — экстремальный страх (I = 8), покупка.**
Путь цены (детерминированный, 90 точек): дни 0–6: с 100 до 89 (−11 %); дни 7–90: восстановление до 141 (+41 % к входу). Индекс за 3 дня растёт 8 → 25 → 40. Стоп Алексея −20 % (по уставу для сценария). Итог: стоп не тронут; результат +41 %. Подпись на дне: «День 5: −11 %. Рука тянется закрыть. Индекс уже 25 — продавцы кончились (урок 5.5: не выключать на дне)».

**Сценарий Б — экстремальная жадность (I = 88), шорт «по индексу».**
Путь цены: дни 0–34: рост 100 → 128 (+28 %), индекс держится 85–92 пять недель; дни 35–52: падение до 105 (−18 % от пика); дни 53–90: боковик 103–110. Шорт Алексея со стопом −10 % → выбит на день 9 при цене 110. Итог: −10 % депозита… и наблюдение, как через месяц цена всё-таки падает на 18 %. Подпись: «Ты был прав по направлению и потерял деньги по таймингу. Жадность растягивается неделями — толпа права подолгу (урок: контртренд без подтверждения ценой — не стратегия)».

**Сценарий Б′ (кнопка «А как правильно?»)**: тот же путь, но действие — «не добавлять длинных позиций, уменьшить размер, ждать подтверждения: закрытие дня ниже 20-дневного минимума». Вход в шорт на день 39 по 119, выход на день 52 по 105 → +12 %. Подпись: «Индекс — фильтр (“не покупай здесь”), а триггер — цена».

Под сценариями — таблица-резюме (заполняется по ходу):

| | Страх (А) | Жадность (Б) |
|---|---|---|
| Как разряжается | за 1–3 дня | неделями |
| Что делает индекс | говорит «продавцов почти нет» | говорит «покупателей почти нет» |

### 2.2. Педагогические цели
1. Между публикацией и твоим исполнением стоит **цепочка задержек**; каждая — секунды или доли секунды, но они складываются.
2. Движение цены после новости **распадается экспоненциально**: половина уходит за первые 5–10 секунд.
3. Заработок = **остаток движения к моменту исполнения минус издержки круга (14–20 б.п.)**. Правильность понимания новости здесь ни при чём.
4. Существует **пороговая задержка безубыточности** `t* = τ·ln(M / C)`; для человека она недостижима, для бота из урока (< 0,4 с) — достижима, для канала-репоста — нет.
5. Ты не соревнуешься с фондами на колокации (0,05 с) — твоё поле начинается там, где новость ещё не разобрана толпой, и заканчивается там, где остаток меньше издержек.

**Критерий освоения:** ученик правильно оценивает остаток движения при задержке 40 с (≈ 2 % от исходного) и в финальной проверке выбирает «решает остаток движения к моменту исполнения минус издержки».

### 2.3. Модель

**Движение цены после новости:**
`R(t) = M · exp(−t / τ)`, где `M` — полная величина движения (б.п.), `τ = t_half / ln 2`, `t_half` — время, за которое уходит половина движения.
Значения по умолчанию: `M = 60 б.п.`, `t_half = 7 с` (урок: «половина за 5–10 с») → `τ ≈ 10,1 с`.
«Уже забрали до тебя» = `M − R(t)`; в процентах = `1 − exp(−t/τ)`.

**Чистый результат участника с задержкой `t`:** `Net(t) = R(t) − C`, где `C` — издержки круга (б.п.).
Пресеты `C`: 14 / 17 (по умолчанию) / 20 б.п. с тултипом-разложением из урока 1.8: «заявка по рынку 5,5 + половина спреда 0,5–1 + проскальзывание 1–3 = 7–10 б.п. за сторону, ×2 за круг».

**Порог безубыточности:** `t* = τ · ln(M / C)`. При M=60, C=17: `t* ≈ 12,7 с`. Если `M ≤ C` — `t*` не существует: подпись «Эта новость не окупает даже мгновенное исполнение».

**Задержка твоего конвейера** — сумма блоков (мс), значения из таблицы урока:

| Блок конвейера | Диапазон (мс) | По умолчанию | Ползунок? |
|---|---|---|---|
| Доставка сообщения через протокол Телеграма | 120–250 | 180 | нет (тултип) |
| Дедупликация (одна новость в 20 каналах = один сигнал) | 1–5 | 3 | нет |
| Извлечение тикера | 1–2 | 2 | нет |
| Оценка тональности (модель) | 10–30 | 20 | нет |
| Отправка заявки на биржу (сеть) | 50–250 | 120 | да, 50–250 |
| Исполнение на бирже (сведение + подтверждение) | 20–150 | 60 | да |
| **Итого бот** | | **≈ 385 мс** | |

Плюс **источник новости**: переключатель «канал — первоисточник» (добавка 0 с) / «канал — репост» (ползунок `t_репост` 5–600 с, по умолчанию 45 с). Тултип: «Русскоязычные каналы дают преимущество только там, где они опережают англоязычные источники (урок)».

**Профили участников (дорожки гонки):**

| Дорожка | Задержка | Как показана |
|---|---|---|

Движение мастер-ползунка выше суммы блоков автоматически добавляет разницу в строку «человеческое время (прочитал, подумал, нажал)», чтобы разложение всегда сходилось с итогом.

### 2.5. Сценарий взаимодействия

**Шаг 0 — прогноз до раскрытия (обязательный).** Экран гонки размыт. Вопрос:
> «Новость вышла. Ты увидел её в канале, прочитал, понял, что это хорошо, открыл терминал и нажал “купить”. Прошло 40 секунд. Какая часть движения цены тебе осталась?»
> ○ около 90 % — «новость же только вышла»
> ○ около половины
> ○ около 2 %

Раскрытие → автозапуск гонки на скорости ×10 с задержкой ученика 40 с. Подпись: «Ты ожидал …, осталось 1,1 б.п. из 60. Половина ушла за первые 7 секунд — пока ты читал заголовок».

**Шаг 1 — гонка.** Четыре дорожки стартуют одновременно; ось времени — **логарифмическая** (0,01 с → 5 мин), чтобы 0,05 с и 300 с уместились. Над дорожкой при финише всплывает «остаток: X б.п.». Одновременно на правом графике по кривой `R(t)` ползёт точка, а «пирог» движения (кольцевая диаграмма над графиком) съедается: сектора «забрано до тебя» / «твой остаток» / «издержки». Скорость «реальная» — честные 60 с реального времени с таймером (кнопка предупреждает: «Это долго. В этом и смысл»).

**Шаг 2 — конвейер.** Ученик двигает ползунки блоков и мастер-ползунок; ИТОГ и позиция «твоего бота» на гонке и на кривой обновляются мгновенно. Переключение на «репост» сдвигает старт бота на `t_репост`: подпись «Твой конвейер быстрый, но новость дошла до канала через 45 с — ты бежишь быстро, но стартовал поздно».

**Шаг 3 — параметры новости.** Ползунки `M` и `t_half`, пресеты издержек. Пороговая задержка `t*` пересчитывается и отмечается вертикальной линией на кривой; дорожки, финишировавшие правее `t*`, помечаются красным флажком «минус». При `M ≤ C` — сообщение про новость, которая не окупает даже мгновенный вход.

**Шаг 4 (обязательный) — «Серия из 20 новостей».** Кнопка «Прогнать 20 новостей». Генератор (сид `20221010`): для каждой новости `M ~ логнормальное(медиана 45, σ 0,6)`, клип 5–200 б.п.; знак случайный (бот торгует в сторону тональности — считаем направление угаданным в 85 % случаев, в 15 % — против: остаток берётся со знаком минус). **30 % сообщений — реклама/дубли**: движения нет (`M = 0`), но бот без фильтров всё равно входит и платит `C`.
Две колонки результата:
- «Бот без фильтров (белый список, дедупликация выключены)»: сумма `Net` по всем 20.
- «Бот с фильтрами»: сумма по 14 настоящим.
- «Ручной трейдер (45 с)»: сумма по 14 настоящим.
Показ построчно (таблица 20 строк с цветом) и итог. При параметрах по умолчанию ожидаемо: бот с фильтрами ≈ +250…+400 б.п. суммарно, без фильтров — минус ~100 б.п. на мусоре, ручной — стабильно отрицательно (14 × ≈ −16). Подпись: «Ловушка спама из урока: без белого списка и дедупликации бот совершает сделки на рекламе казино».

**Шаг 5 — финальная проверка.**
> «Что решает в новостной стратегии?»
> ○ «Правильно ли я понял, хорошая новость или плохая» → неверно: «Ты понял правильно и потерял: остаток 1 б.п. при издержках 17»
> ○ «Сколько движения осталось к моменту, когда исполнилась моя заявка, минус издержки круга» → верно
> ○ «Есть ли у меня доступ к секретным каналам» → неверно: «Опережение живёт в скорости сбора и обработки, а не в секретных каналах (урок)»
> ○ «Успеть быстрее фонда на колокации» → неверно: «Это гонка не твоя (урок 4.5). Твоя граница — порог безубыточности t*, а не 0,05 с»

При верном ответе — карточка формулы на русском: «Заработок = остаток движения к моменту исполнения − издержки круга. Порог: t* = τ · ln(M / C)» с расшифровкой каждой буквы по-русски.

- [ ] Кольцевая диаграмма «пирога движения» синхронизирована с положением точки на кривой.
- [ ] Издержки показаны как полоса 14–20 б.п. с выбранным пресетом; тултип раскладывает круг по уроку 1.8.
- [ ] Ни одного английского слова вне тултипов; «б.п.» с тултипом; бейдж «учебная модель» на кривой.
- [ ] `prefers-reduced-motion`: гонка заменяется мгновенной расстановкой финишей + кнопкой «показать по шагам».
- [ ] Клавиатурное управление всеми ползунками; `aria-valuetext` вида «задержка 45 секунд — ручной трейдер».

### 2.9. Чего не делать
- Не показывать реальные новости, тикеры, названия каналов или бирж — только «новость», «монета X».
- Не давать ползунку задержки опускаться ниже 0,4 с для «твоего бота» (это сместит внимание в гонку с колокацией, которую урок 4.5 прямо запрещает).
- Не рисовать кривую остатка без полосы издержек — без неё остаток выглядит «прибылью».
- Не использовать линейную ось времени на гонке: 0,05 с и 300 с не поместятся, и главный контраст пропадёт.
