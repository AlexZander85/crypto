# Детальные спеки для реализации: Б9 «Пыль» и Б11 «Комиссия у 50%»

Общие соглашения для обоих интерактивов (наследуются из методического слоя ТЗ‑3):

- **Один интерактив = одно заблуждение.** У каждого ниже явно указано, какую фразу новичка он ломает и какой экран это делает.
- **Русский без английского.** Все подписи, кнопки, оси — по‑русски. Английские слова допустимы только внутри всплывающей подсказки «на площадке это называется…». Токены с подсказкой размечаются так же, как в текстах уроков: `data-tooltip-term="…"`.
- **Числа — из текста урока.** Дефолты и проверочные кейсы взяты из уроков 72 (Б9), 67 и 74 (Б11). Ниже для каждого числа дана расчётная таблица — используй её как набор автотестов.
- **Ничего внешнего.** Никаких запросов к реальным кранам, к API Polymarket и т.п. Всё считается локально по формулам из урока.
- **Никаких обещаний доходности.** Интерактивы показывают арифметику, а не «где заработать».

## Б9 · «Пыль» — таймлапс копилки крана

### 1. Паспорт

| Поле | Значение |
|---|---|
| ID | `sim-b9-dust` |
| Урок | 72 · Б9 «Крипто‑краны: почему этот способ умер» |
| Тип | ВИЗ + СИМ (анимированная симуляция с таймлапсом), финальный микро‑ИГР |
| Целевое заблуждение | «Крану ещё можно — копейка к копейке, на пиво насобираю» |
| Что ломает | Показывает, что (а) награда никогда не догоняет комиссию сети в разумное время, (б) когда всё же догоняет — комиссия съедает всё при выводе, (в) даже в дешёвой сети часовая ставка за клики — центы. Итог урока: «сначала считай издержки, потом время». |
| Место в уроке | После блока «Аналогия» (киоск с лимонадом), перед «Итог урока». Существующий калькулятор «Кран: reward vs fee» показывает один срез; «Пыль» показывает **время** — они не дублируют друг друга. Если хочешь оставить один — оставь «Пыль», перенеся из калькулятора пресеты сетей. |
| Движки | Не требует сквозных движков. Использует языковой слой «Ткни в непонятное». |
| Персонаж | Алексей (сквозной герой Py‑уроков) решил «подкопить на кране, пока бот учится». |

### 2. Педагогическая цель и критерий освоения

Ученик после интерактива должен **сам** сформулировать три факта:

1. Отношение «награда / комиссия» ≈ 1/1000 — столбик визуально не растёт; чтобы увидеть рост, нужна «лупа ×100».
2. Даже дорастив до комиссии, при выводе получаешь ≈ 0 — комиссия списывается из накопленного.
3. Настоящая цена крана — часы у экрана и просмотренная реклама; часовая ставка — центы даже в сети с нулевой комиссией.

**Критерий освоения (блокирует кнопку «Готово»):** пройти финальный микро‑квиз из 2 вопросов (п. 7) и обратную задачу «какая награда за клик нужна, чтобы кран платил 300 ₽/час» с допуском ±15 %.

### 3. Модель данных и параметры

```
state = {
  mode: 'fixed' | 'live_gas' | 'retro' | 'cheap_chain',   // режим сцены
  reward_per_claim_usd: 0.001,   // награда за один клик (по уроку ≈ $0.001)
  cooldown_min: 5,               // таймер крана между кликами
  active_sec_per_claim: 30,      // капча + реклама: время активного участия
  ads_per_claim: 2,              // сколько рекламных показов за клик
  fee_usd: 1.00,                 // комиссия сети за вывод (по уроку ≥ $1)
  safety_factor: 3,              // «запас прочности» из блока «Глубже»
  rub_per_usd: 90,               // для подсказки в рублях (константа, как в 5.3)
  // накопители
  claims: 0, balance_usd: 0, calendar_min: 0, active_min: 0, ads_seen: 0,
  // таймлапс
  speed: 1 | 60 | 600 | 3600,   // 1 сек реального времени = N сек симуляции
  running: false,
  withdrawn: null                // результат вывода {gross, fee, net}
}
```

**Диапазоны ползунков (панель «Настройки», по умолчанию свёрнута):**

| Параметр | Диапазон | Шаг | Дефолт | Подпись |
|---|---|---|---|---|
| `reward_per_claim_usd` | 0.0001 – 0.05 | лог‑шкала | 0.001 | «Награда за клик, $» |
| `cooldown_min` | 1 – 60 | 1 | 5 | «Таймер крана, мин» |
| `active_sec_per_claim` | 10 – 120 | 5 | 30 | «Капча и реклама, сек» |
| `fee_usd` | 0.001 – 30 | лог‑шкала | 1.00 | «Комиссия сети за вывод, $» |
| `safety_factor` | 1 – 5 | 1 | 3 | «Запас прочности (×комиссия)» |

**Пресеты режима (кнопки‑чипы над сценой):**

| Режим | Что меняет | Зачем |
|---|---|---|
| **«Сегодня, дорогая сеть»** (`fixed`, дефолт) | reward 0.001, fee 1.00, комиссия неподвижна | базовая арифметика урока: 1000 кликов до линии, после вывода — ноль |
| **«Сегодня, газ скачет»** (`live_gas`) | то же, но `fee` каждые 60 симулированных минут случайно блуждает в коридоре ×0.7…×2.5 от базы, с редкими всплесками ×5 (вероятность 3 % на шаг). Линия комиссии на сцене «дышит». | столбик почти дорастает — линия уходит; иллюстрация «запаса прочности» |
| **«2012 год»** (`retro`) | reward 0.01, fee 0.001 | почему краны когда‑то работали: линия комиссии — внизу, столбик перепрыгивает её первым же кликом |
| **«Дешёвая сеть»** (`cheap_chain`) | reward 0.001, fee 0.005 | честный ответ на «а на Solana?»: линия достигается за 5 кликов, но панель ставки показывает $0.12/час — второе, независимое от комиссии, «убийство» крана |

### 4. Экран (три зоны, десктоп слева направо; мобилка — сверху вниз)

**Зона А «Кран» (слева, ~25 %)**
- Большая кнопка **«Кликнуть кран»** (ручной режим). При клике: анимация капли, +reward к балансу, счётчики +1 клик, +ads, +active_sec, +cooldown к календарному времени. Кнопка блокируется на визуальные 0.4 с (не на реальный cooldown — иначе ученик уйдёт).
- Кнопка **«Запустить таймлапс ▶ / Пауза»** и переключатель скорости: «1×», «1 мин = 1 сек», «10 мин = 1 сек», «1 час = 1 сек». По умолчанию после 5 ручных кликов появляется подсказка: «Рука устала? Включи таймлапс».
- Счётчики (крупно): **Кликов · Реклам просмотрено · Времени у экрана (активного) · Времени календарного**.
- Мелкая строка под счётчиками: «Что ещё отдал: e‑mail, адрес кошелька, IP» — статичная подпись, ссылка‑подсказка на урок Б8 («настоящий дроп не просит seed»).

**Зона Б «Копилка» (центр, ~45 %) — главный визуальный элемент**
- Вертикальный сосуд‑столбик. Шкала Y **линейная**, верх сосуда = `fee × safety_factor × 1.2`. Две горизонтальные линии:
  - сплошная красная — **«Комиссия сети за вывод: $1.00»**;
  - пунктирная оранжевая — **«Разумный порог вывода: 3 × комиссия = $3.00»** (подпись формулы из урока: «перевод имеет смысл, когда сумма > комиссия × запас прочности»).
- Столбик накопленной «пыли» растёт снизу. При дефолтах после 10 кликов его высота — 1 % от линии комиссии: **на экране ~1–2 пикселя**. Это намеренно.
- Кнопка‑переключатель **«Лупа ×100»**: показывает врезку‑увеличение нижней части сосуда (0–1 % высоты), где столбик виден и растёт. При включённой лупе над ней подпись: «Так выглядит рост без лупы →» и стрелка на невидимый столбик. Лупа — ключевой педагогический момент: ученик сам осознаёт масштаб.
- Кнопка **«Вывести на кошелёк»**: активна всегда. Если `balance < fee` — модалка: «Сеть спишет $1.00, у тебя $0.012. Перевод не пройдёт: пыль». Если `balance ≥ fee` — анимация: столбик обрушивается на высоту `fee`, остаток `balance − fee` остаётся зелёным (при дефолтах — ≈ $0.00–0.01), крупная подпись «После вывода: $0.00». В режиме `live_gas` при клике берётся текущее значение `fee`.
- В режиме `live_gas` красная линия анимированно движется; при всплеске — короткий бейдж «Газ вырос ×5».

**Зона В «Арифметика» (справа, ~30 %) — обновляется каждый тик**

```
Накоплено:                $0.0120  (≈ 1,08 ₽)
Комиссия сети:            $1.0000
До комиссии осталось:     988 кликов ≈ 82,3 ч календарных · 8,2 ч у экрана
Часовая ставка (у экрана): $0.12/ч  ≈ 10,8 ₽/ч
Часовая ставка (календарь):$0.012/ч ≈ 1,1 ₽/ч
После вывода останется:   $0.00
Реклам ты посмотришь до вывода ещё: 1 976
```

Под таблицей — одна строка сравнения, без морали: «Для ориентира: любая подработка — от 300 ₽/ч» (константа `benchmark_rub_per_hour = 300`, вынести в конфиг).

### 5. Формулы (единый источник истины; вынести в чистый модуль без UI)

```
claims_to_fee      = ceil(max(0, fee_usd − balance_usd) / reward_per_claim_usd)
calendar_h_to_fee  = claims_to_fee × cooldown_min / 60
active_h_to_fee    = claims_to_fee × active_sec_per_claim / 3600
rate_active_usd_h  = reward_per_claim_usd × 3600 / active_sec_per_claim
rate_calendar_usd_h= reward_per_claim_usd × 60 / cooldown_min
net_after_withdraw = max(0, balance_usd − fee_usd)      // если balance < fee → перевод невозможен
ads_to_fee         = claims_to_fee × ads_per_claim
// обратная задача (финал):
required_reward_for(target_rub_h) = target_rub_h / rub_per_usd × active_sec_per_claim / 3600
```

**Живой газ (`live_gas`), шаг раз в 60 симулированных минут:**
```
fee_t+1 = clamp(fee_t × exp(N(0, 0.25)), 0.7 × fee_base, 2.5 × fee_base)
с вероятностью 0.03: fee_t+1 = 5 × fee_base на 3 шага, затем возврат к блужданию
```
Сид генератора фиксируй по сессии, чтобы «Повторить» давал тот же ряд.

**Контрольная таблица для автотестов (дефолты: reward 0.001, cooldown 5, active 30, fee 1.00):**

| Величина | Ожидание |
|---|---|
| claims_to_fee при balance 0 | 1000 |
| calendar_h_to_fee | 83.33 ч |
| active_h_to_fee | 8.33 ч |
| rate_active_usd_h | $0.12/ч (10.8 ₽) |
| rate_calendar_usd_h | $0.012/ч (1.08 ₽) |
| net_after_withdraw при balance 1.000 | $0.00 |
| ads_to_fee | 2000 |
| required_reward_for(300 ₽/ч) | $0.0278 за клик (в 27.8 раза больше дефолта) |
| Режим retro: claims_to_fee | 1 (0.01 ≥ 0.001 после первого клика), net = $0.009 |
| Режим cheap_chain: claims_to_fee | 5; rate_active остаётся $0.12/ч |

### 6. Сценарий прохождения (guided flow, шаги подсвечиваются, но не блокируют)

1. **Стартовый экран**: сосуд пустой, подпись‑задача: «Алексей решил подкопить на кране, пока учит Python. Нажми кран 10 раз». Кнопка таймлапса скрыта.
2. После 10 кликов: всплывает «Найди столбик на сосуде. Не видно? Включи лупу». Появляются лупа и таймлапс.
3. Ученик включает таймлапс «1 час = 1 сек». За 83 секунды реального времени столбик доползает до красной линии (в `fixed`). Одновременно в зоне В растут часы и рекламы. При достижении линии таймлапс автопаузится с подписью: «Дошёл. 3,5 суток календарных, 8 часов у экрана, 2000 реклам. Выводи».
4. Клик «Вывести» → столбик обнуляется → карточка **«Итог смены»**:
   > Отдал: 8,3 ч внимания, 2 000 рекламных показов, e‑mail и адрес кошелька.
   > Получил: $1.00. После комиссии: **$0.00**.
   > Часовая ставка: 10,8 ₽/ч.
5. Предложение: «Попробуй другие миры» → чипы режимов. Каждый режим завершается своей карточкой (см. таблицу режимов: в `live_gas` карточка появляется, когда ученик нажимает «Вывести» на подступах к линии и получает «Газ вырос, ты снова ниже комиссии»; после 3 таких попыток — подсказка про пунктир «запас прочности»).
6. После ≥ 2 пройденных режимов открывается финал (п. 7).

### 7. Финал: квиз + обратная задача (критерий освоения)

**Вопрос 1.** «Что убило краны?»
- ☐ Кранов стало меньше
- ☑ Комиссии сетей выросли на порядки, награды — нет
- ☐ Биткоин стал слишком дорогим, чтобы его раздавать
Объяснение при ошибке: цитата урока — «Затем комиссии сетей выросли на порядки, а награды кранов — нет».

**Вопрос 2.** «В дешёвой сети комиссия $0.005 — кран снова работает?»
- ☐ Да, столбик дорастает за 5 кликов
- ☑ Нет: часовая ставка всё равно ≈ 11 ₽/ч — время дороже награды
- ☐ Да, если кликать быстрее
Объяснение: «Урок для любого способа: сначала считай издержки, потом время».

**Обратная задача (ползунок).** «Подбери награду за клик, при которой кран платит 300 ₽/ч (капча 30 сек)». Ответ принимается в коридоре $0.024–$0.032. После ответа подпись: «Сегодняшние краны платят в ~28 раз меньше. Честная замена, где за активность платят по‑настоящему: тестнеты и ретродропы — урок Б8».

### 8. Языковой слой

Токены с подсказкой (`data-tooltip-term`): **пыль** → «столь малая сумма, что перевод дороже её самой (dust)»; **комиссия сети** → «плата за исполнение перевода (gas fee)»; **кран** → «сайт, раздающий крошечные суммы за клики (faucet)»; **таймлапс** → «ускоренная прокрутка времени». Слова «faucet», «gas», «dust» на экране не появляются иначе как в подсказках.

### 9. Доступность, мобилка, производительность

- Все анимации подчиняются `prefers-reduced-motion`: вместо плавного роста — дискретные обновления раз в секунду.
- Мобилка: зоны стеком А→Б→В; лупа открывается как всплывающая карточка; сосуд не ниже 220 px высотой.
- Таймлапс — один `requestAnimationFrame`‑цикл; при скорости «1 ч = 1 сек» за тик добавляется 12 кликов (60/cooldown), не 12 отдельных анимаций.
- Клавиатура: кнопка крана — пробел/Enter; режимы — стрелки.

### 10. Аналитика (события)

`b9_start`, `b9_manual_click` (счётчик), `b9_loupe_on`, `b9_timelapse_speed`, `b9_withdraw_attempt {balance, fee, net}`, `b9_mode_switch {mode}`, `b9_quiz_answer {q, correct}`, `b9_inverse_task {value, accepted}`, `b9_complete`. Метрика эффективности: доля учеников, включивших лупу (ожидание > 80 %), и доля верных ответов на вопрос 2 с первой попытки.

### 11. Критерии приёмки

- [ ] При дефолтах после 10 ручных кликов столбик без лупы неотличим от нуля (≤ 2 px), с лупой — виден и растёт.
- [ ] Таймлапс «1 ч = 1 сек» доводит до линии комиссии за 83 ± 1 с реального времени; счётчики совпадают с контрольной таблицей.
- [ ] «Вывести» при balance < fee не уменьшает баланс и показывает отказ; при balance ≥ fee обнуляет до `net_after_withdraw`.
- [ ] Режим `live_gas` воспроизводим при «Повторить» (фиксированный сид); линия комиссии не выходит за коридор.
- [ ] Режимы `retro` и `cheap_chain` дают числа из таблицы.
- [ ] Ни одного английского слова вне подсказок; все подсказки ведут на термины урока.
- [ ] Финал недоступен до прохождения ≥ 2 режимов; обратная задача принимает $0.024–0.032.
- [ ] Нет ссылок на реальные сайты‑краны.

### 12. Что НЕ делать

- Не добавлять «реальные курсы» токенов, не подключать API.
- Не показывать заработок в криптовалюте (сатоши) — только $ и ₽, иначе пропадает эффект масштаба.
- Не превращать в кликер‑игру с ачивками: единственная «награда» — понимание.

## Б11 · «Комиссия у 50%» — кривая тейкер‑комиссии и весы арбитража

### 1. Паспорт

| Поле | Значение |
|---|---|
| ID | `sim-b11-fee-curve` |
| Урок | 74 · Б11 «Стратегии Polymarket: от чистого арбитража до продажи хвостов» (формула введена в уроке 67 · Б6) |
| Тип | ВИЗ + СИМ (интерактивная кривая + весы) + ИГР (сортировка пяти рынков) |
| Целевое заблуждение | «Если Да + Нет < $1 — арбитраж всегда прибылен» |
| Что ломает | Комиссия тейкера — не константа: `комиссия = C × 0.06 × p × (1 − p)` на долю. Максимум ровно в середине шкалы вероятностей, ноль у краёв. Значит «очевидные» арбитражи в районе 50/50 — самые дорогие: при спреде 2 цента у 50 % ты в минусе, у 10 % — в плюсе. |
| Место в уроке | После блока «Подробнее», перед «Глубже» (там формула упоминается текстом). Существующий «Полимаркет‑сканер арбитража» дополняется кнопкой «учесть кривую комиссии» → открывает этот интерактив с подставленными ценами. |
| Движки | Не требует; языковой слой обязателен. |
| Числа урока | Да = $0.55, Нет = $0.40 → затраты $0.95, выплата $1.00 (урок 74); коэффициент 0.06 (урок 74), формула `fee ≈ C × feeRate × p × (1−p)` (урок 67). |

**Честная оговорка в интерактиве (статичная строка под кривой):** «Коэффициент 0.06 — из урока; площадка может менять ставку, а на части рынков комиссия нулевая. Форма кривой от этого не меняется: дороже всего — середина. Актуальную ставку смотри на площадке перед сделкой». Коэффициент вынесен в ползунок `fee_rate` (0…0.10, дефолт 0.06). При `fee_rate = 0` интерактив показывает наивную картину «весь спред — прибыль» — это и есть заблуждение, которое ученик увидит контрастом.

### 2. Педагогическая цель и критерий освоения

Ученик должен уметь:
1. По цене исхода сказать, где комиссия больше: «у 50 % — максимум ($0.015 на долю при ставке 0.06), у 1 % и 99 % — почти ноль».
2. Посчитать чистый результат пары «Да + Нет»: `1 − (цена Да + цена Нет) − комиссия обеих ног`.
3. Отличить настоящий арбитраж от мнимого: **минимальный спред безубытка** у середины ≈ 3 цента, у краёв — доли цента.

**Критерий освоения:** верно рассортировать ≥ 4 из 5 рынков в мини‑игре и ответить на вопрос «почему середина дороже» (выбор из трёх).

### 3. Модель данных

```
state = {
  fee_rate: 0.06,           // коэффициент кривой (по уроку)
  p_yes: 0.55,              // цена доли «Да», $ за долю
  p_no: 0.40,               // цена доли «Нет»
  shares: 100,              // C — число пар долей
  fixed_costs_usd: 0,       // перевод между площадками / вывод; для межплатформенного режима
  show_relative: false,     // переключатель «Глубже»: комиссия в % от вложенного
  observed_spread: 0.02,    // для карты прибыльности: наблюдаемый спред 1 − (Да+Нет)
  game: { answers: [], done: false }
}
```

Ползунки:

| Параметр | Диапазон | Шаг | Дефолт | Подпись |
|---|---|---|---|---|
| `p_yes` | 0.01 – 0.99 | 0.005 | 0.55 | «Цена доли „Да“, $» |
| `p_no` | 0.01 – 0.99 | 0.005 | 0.40 | «Цена доли „Нет“, $» |
| `shares` | 10 – 10 000 | лог | 100 | «Сколько пар долей покупаешь» |

| `observed_spread` | 0 – 0.10 | 0.0025 | 0.02 | «Наблюдаемый спред: 1 − (Да + Нет)» |

### 4. Формулы (чистый модуль без UI)

```
fee_per_share(p)   = fee_rate × p × (1 − p)                 // $ на одну долю
fee_leg(p, C)      = C × fee_per_share(p)
gross_per_pair     = 1 − (p_yes + p_no)                      // до комиссий
fees_per_pair      = fee_per_share(p_yes) + fee_per_share(p_no)
net_per_pair       = gross_per_pair − fees_per_pair
net_total          = C × net_per_pair − fixed_costs_usd
breakeven_pairs    = fixed_costs_usd / net_per_pair          // если net_per_pair > 0, иначе ∞
// карта прибыльности (симметричная пара p и 1−p):
min_spread(p)      = 2 × fee_rate × p × (1 − p)              // спред безубытка при середине p
// «Глубже»: комиссия относительно вложенного в долю
fee_relative(p)    = fee_per_share(p) / p = fee_rate × (1 − p)
```

| 0.55 | 0.014850 | нога «Да» из урока |
| 0.40 | 0.014400 | нога «Нет» из урока |
| 0.90 / 0.10 | 0.005400 | |
| 0.99 / 0.01 | 0.000594 | ≈ ноль у краёв |
| 0.03 | 0.001746 | |

| 0.285 | 0.012227 | |

**Пары (net_per_pair):**

|---|---|---|---|---|---|---|
| Урок | 0.55 | 0.40 | 0.0500 | 0.02925 | **+0.02075** | прибыльно (2,08 ц) |

**Карта прибыльности:** `min_spread(0.5) = 0.030`; `min_spread(0.9) = 0.0108`; `min_spread(0.99) = 0.00119`. При `observed_spread = 0.02` пересечения с кривой: **p ≈ 0.211 и p ≈ 0.789** (решение `0.12·p·(1−p) = 0.02`). Между ними — красная зона.

### 5. Экран (три панели сверху вниз; на десктопе панели 1 и 2 рядом, 3 — под ними)

**Панель 1 «Кривая комиссии»**
- График: ось X — «Цена доли (вероятность по мнению рынка)» 0…100 %, ось Y — «Комиссия за одну долю, центов» 0…2 ц (авто‑масштаб от `fee_rate`). Кривая‑парабола `fee_per_share(p)`.
- Перетаскиваемая точка на кривой (и клавиши ←/→ с шагом 1 %). Рядом с точкой карточка: «При цене $0.55 комиссия 1,49 ц на долю. При 100 долях — $1.49».
- Две подсветки: вершина при 50 % с подписью «Максимум: 1,50 ц»; края с подписью «≈ 0 у 1 % и 99 %».
- Кнопка «Показать формулу» → строка: `комиссия = C × 0.06 × p × (1 − p)`, где каждый символ кликабелен: C → «число долей», p → «цена доли», 0.06 → «коэффициент площадки (ползунок ниже)».
- Ползунок `fee_rate`. При 0 кривая ложится на ось, подпись: «Мир без комиссий: так выглядит арбитраж в голове новичка».
- Переключатель «Глубже: комиссия в % от вложенного» (`show_relative`): рисует вторую кривую `fee_rate × (1−p)` на правой оси. Подпись: «В долларах на долю у краёв комиссия почти ноль, но относительно вложенного при покупке дешёвой стороны она заметна: доля за $0.03 стоит 5,8 % сверху». Это дополнение уровня «Глубже», по умолчанию выключено.

**Панель 2 «Весы одной пары „Да + Нет“»**
- Горизонтальная полоса длиной ровно **$1.00** («Выплата площадки: $1 за пару в любом исходе»). Внутри слева направо сегменты: цена Да (синий) · цена Нет (оранжевый) · комиссия ноги Да (синяя штриховка) · комиссия ноги Нет (оранжевая штриховка) · **остаток** (зелёный — чистая прибыль). Если сумма сегментов > $1, красный сегмент выступает за правый край с подписью «Убыток».
- Под полосой числа: «Затраты на пару: $0.95 · Комиссии: $0.029 · **Чистыми: +$0.0208 на пару**». Ниже: «На 100 пар: +$2.08. Прочие издержки: $0. Итого: +$2.08». При `fixed_costs_usd > 0`: «Безубыток с $3.00 прочих издержек — от 145 пар».
- Ползунки `p_yes`, `p_no`, `shares`, `fixed_costs_usd`. Пресет‑кнопка «Пример из урока» возвращает 0.55/0.40/100/0.
- Связь с панелью 1: при движении `p_yes` точка на кривой синхронно едет; две тонкие вертикали на кривой показывают обе ноги.
- Пресет «Межплатформенный»: `fixed_costs_usd = 3`, подпись «переводы USDC между площадками и вывод — грубая оценка; плюс время в пути и риск разной резолюции».

**Панель 3 «Карта прибыльности: где арбитраж настоящий»**
- График: ось X — «Середина рынка (цена „Да“)» 0…100 %; ось Y — «Спред 1 − (Да + Нет), центов» 0…5 ц. Кривая `min_spread(p)` — «Порог безубытка». Горизонтальная линия `observed_spread` (ползунок, дефолт 2 ц), подпись «Такой спред ты увидел на экране».
- Область над кривой — зелёная («прибыль после комиссий»), под кривой — красная. При спреде 2 ц зелёные зоны: p < 21 % и p > 79 %; между ними красное с подписью «У 50 % не хватает: нужно ≥ 3 ц».
- Точка текущей пары из панели 2 отображается на карте.

### 6. Мини‑игра «Пять рынков» (ИГР, критерий освоения)

Открывается после того, как ученик хотя бы раз подвигал точку на кривой и один раз изменил цены на весах.

Пять карточек (кейсы A, B, D, E, F из таблицы; порядок случайный):
```
Карточка: «Будет ли дождь в воскресенье?»   Да $0.49 · Нет $0.49 · Да + Нет = $0.98
Действие: [Арбитраж есть] [Мнимый] 
```
Тексты событий — нейтральные и вымышленные (погода, счёт матча вымышленных команд, «выйдет ли обновление до пятницы»), без политики и реальных лиц.

После ответа карточка раскрывается: полоса весов из панели 2 с числами и вердикт. Ошибка объясняется одной фразой: «Спред 2 ц, а комиссия двух ног у 49 % — 3 ц. Середина — самое дорогое место шкалы». Для кейса E: «+0,01 ц? Это ноль. Любой перевод между площадками делает его минусом».

Итоговый экран: «Настоящих арбитражей было 2 из 5 (B, F). Твой результат: X из 5». Затем контрольный вопрос:

«Почему у 50 % комиссия максимальна?»
- ☑ Произведение p × (1 − p) наибольшее при p = 0.5
- ☐ Там больше всего сделок, и площадка поднимает цену
- ☐ Потому что у 50 % риск для площадки выше

При ≥ 4/5 и верном ответе — «Готово», иначе кнопка «Ещё пять» (второй набор: те же формулы, другие цены: 0.51/0.475 → −; 0.06/0.925 → +; 0.65/0.33 → −; 0.98/0.012 → + (проверь: gross 0.008, fees 0.06·0.98·0.02+0.06·0.012·0.988 = 0.001176+0.000711 = 0.00189 → +0.0061); 0.80/0.185 → gross 0.015, fees 0.0096+0.00905 = 0.01865 → −).

### 7. Тексты обратной связи (готовые строки)

- Подпись при `net_per_pair < 0`: «Да + Нет < $1, а ты всё равно в минусе: комиссии двух ног съели спред».
- Подпись при `0 ≤ net_per_pair < 0.002`: «Технически плюс, фактически ноль: любые прочие издержки переводят в минус».
- Подпись при `fee_rate = 0`: «Без комиссий каждый спред — прибыль. Так думает новичок; вернись к 0.06».
- Подпись у вершины кривой: «Здесь живут „очевидные“ арбитражи — и здесь они дороже всего».
- Подпись у краёв: «У краёв комиссия почти ноль, но и спреды тоньше, и ликвидность хуже — см. урок Б10».

### 8. Языковой слой

На экране только «Да» / «Нет». Подсказки: **«Да»/«Нет»** → «доли исходов; на площадке — YES / NO»; **тейкер‑комиссия** → «комиссия того, кто берёт цену из стакана рыночной заявкой (taker)»; **спред пары** → «насколько Да + Нет дешевле $1»; **безубыток** → «результат ровно ноль после всех издержек»; **резолюция** → «финальный расчёт рынка по факту события (урок Б10)». Слово «Polymarket» допустимо в подписи источника формулы (это имя площадки, оно и в тексте урока).

### 9. Доступность и мобилка

- Точка на кривой управляется клавиатурой; значения озвучиваются через `aria-live`.
- Мобилка: панели стеком; кривая не ниже 200 px; ползунки крупные; мини‑игра — карточки на весь экран по одной с свайпом.
- `prefers-reduced-motion`: без анимации сегментов полосы.

### 10. Аналитика

`b11_curve_drag {p}`, `b11_fee_rate_change {rate}`, `b11_relative_toggle`, `b11_pair_change {p_yes, p_no, net}`, `b11_preset {name}`, `b11_game_answer {case, answer, correct}`, `b11_quiz {correct}`, `b11_complete {score}`. Метрика: доля правильно решённого кейса A (0.49/0.49) с первой попытки — прямой замер целевого заблуждения; цель ≥ 70 % после первого прохождения.

### 11. Критерии приёмки

- [ ] `fee_per_share` и `net_per_pair` совпадают с контрольными таблицами до 4 знака.
- [ ] Пример урока (0.55/0.40) даёт затраты $0.95, комиссии $0.029, чистыми +$0.0208 на пару, +$2.08 на 100 пар.
- [ ] Вершина кривой ровно при 50 %, значение 1,50 ц при `fee_rate = 0.06`; при `fee_rate = 0` кривая на нуле и появляется подпись про «мир без комиссий».
- [ ] Карта прибыльности при спреде 2 ц красит красным диапазон ≈ 21–79 % и зелёным края.
- [ ] Полоса весов всегда длиной $1; переполнение показывается как красный выступ, а не масштабированием.
- [ ] Мини‑игра: правильные ответы — B, F (первый набор); кейс E классифицируется как «мнимый».
- [ ] «Готово» недоступно без ≥ 4/5 и верного ответа на вопрос о p × (1 − p).
- [ ] Ни одного английского слова вне подсказок; строка‑оговорка про изменчивость ставки присутствует.
- [ ] Нет обращений к внешним API и реальных названий событий.

### 12. Что НЕ делать

- Не рисовать «доходность стратегии» и не считать годовые проценты — интерактив только про одну пару и одну кривую.
- Не добавлять стакан заявок и глубину — это «Стакан CLOB YES/NO» из Б10; при желании — ссылка.
- Не использовать реальные политические или спортивные события в карточках.
