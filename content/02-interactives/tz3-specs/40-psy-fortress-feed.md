# ТЗ на реализацию: «Крепость капитала» (П35/П37/П39) и «Лента против базы» (П54–П56)

Документ для агента-разработчика. Стек не навязывается; всё, что помечено **[MUST]**, обязательно к реализации, **[SHOULD]** — желательно, **[MAY]** — по возможности.

---

## 0. Общие требования к обоим интерактивам

### 0.1. Аудитория и язык
- Русскоязычный новичок без английского. **[MUST]** В интерфейсе нет английских слов, кроме тикеров (BTC, USDT) и терминов, у которых в уроке уже есть русская пара. Любой такой токен (PF, DD, OOS, винрейт) оборачивается в компонент «Ткни в непонятное»: клик → русская карточка из словаря приложения (см. 0.5).
- Числа берутся из текстов уроков (ссылки указаны в каждом месте). Если урок числа не даёт — число помечается в интерфейсе как **«учебная модель, не измерение»** (мелкая подпись под блоком). Это методическое требование: не выдавать иллюстрацию за факт (см. блоки «Проверка связи с источником» в П9–П12).

### 0.2. ⚠ Важно про исходные тексты
В PDF-выгрузке уроков Академии психологии строки «✓ Решение:» **перепутаны/повреждены** (например, в П35 «правильным» помечено «разделение по четырём биржам», в П37 — «синонимы»). **[MUST]** Правильные ответы и обоснования брать из абзаца «Почему:» и из «Итог урока», а НЕ из строки «✓ Решение». В этом ТЗ все правильные варианты уже приведены явно.

### 0.3. Сквозной персонаж
Оба интерактива ведёт **Алексей** (герой Py-уроков): депозит 100 000 ₽ (≈1000 $), бот работает 5 месяцев. Его «база» (используется в обоих интерактивах):

| Показатель | Значение | Откуда |
|---|---|---|
| Сделок за 5 мес | 140 | ~28/мес (П1: «30 сделок в месяц») |
| Винрейт | 52 % | учебное |
| Профит-фактор (PF) | 1,35 | FT-09 «рабочая зона 1,3–1,8» |
| Макс. просадка | −9 % | FT-09 «5–15 %» |
| Средний месяц | +2,1 % | П54: «бот делает свои +2 % в месяц» |
| Ожидаемая макс. серия убытков | ln(140)/ln(1/0,48) ≈ 6,7 → **7 подряд** | 5.5, П53 |
| Kill-критерии (устав) | rolling Sharpe 60д < 0,3; просадка > 18 %; Execution Deviation > 25 % | 5.6 `charter.yaml` |

### 0.4. Интеграция с движками из карты V15.1
- **E5 «Журнал внутри приложения»**: оба интерактива умеют записать строку в дневник искажений (П44) с готовыми чипами категорий. Если E5 ещё не собран — писать в локальное хранилище с тем же JSON-контрактом (см. 0.6), чтобы потом мигрировать.

### 1.1. Паспорт
| Поле | Значение |

| Целевое заблуждение | **«Торговать на последние — мотивирует»** (П35); вторичные: «прибыль надо тратить, чтобы чувствовать успех» (П37), «планки нет, больше — всегда лучше» (П39) |

### 1.2. Размещение в уроках
- В П35 — после блока «▸ Глубже» и до «Разбор». Открываются акты 1 → 2 → 3 последовательно.
- В П37 — тот же компонент с параметром `startAct=2` (акт 1 показан свёрнутым, значения берутся из сохранённого состояния или дефолтов).
- В П39 — `startAct=3`.
- **[MUST]** Состояние (капитал, расходы, доли, планка) сохраняется между уроками (`localStorage` ключ `fortress.state`, при наличии профиля — в профиль).

Ползунок долей **[MUST]** — тройной (три сегмента одной полосы, тянутся два разделителя). Подписи сегментов строго по П35:
- **«Вне рынка»** — наличные, вклады, ОФЗ, золото. Подсказка: «Никогда не заводятся на криптобиржи. Щит выживания на 1–2 года жизни».
- **«Холодный крипто-фундамент»** — BTC/ETH на холодном кошельке, без плеч.
- **«Алго-пул»** — деньги под ботами.

### 1.4. Акт 1 — «Стены крепости» (П35)

#### Экран
```
┌──────────────────────────────────────────────────────────────┐
│ [Капитал: 1 000 000 ₽ ▾]   [Расходы в месяц: 60 000 ₽ ▾]      │
│ Пресеты: [Крепость] [На последние] [Всё в крипте] [2 мес] [Своё]
│ ▐████ вне рынка 40 % ▐████ холод 40 % ▐██ пул 20 %▌            │
│                                                              │
│  ┌── ВИЗУАЛ ──┐   Удар по пулу:                              │
│  │ крепость   │   [ −20 % ] [ −50 % ] [ Пул сгорел −100 % ]   │
│  │ 3 стены    │   [ Крипто-зима: холод −60 %, пул −50 % ]     │
│  └────────────┘                                              │
│  РЕЗУЛЬТАТ УДАРА                                             │
│  Потеря: 40 000 ₽ = 4,0 % благосостояния                     │
│  Ощущается как: ×2,5 → «−100 000 ₽» (П10)                    │
│  Чтобы вернуть пул: +25 % (0.12)                             │
│  Если доход прекратится завтра, крепость держится: 6,7 мес   │
│  ▌ТЕРМОМЕТР СТРЕССА 2/10 ▌ зона: зелёная                      │
│  → Решения: по уставу, вмешательств не требуется             │
│  Тот же удар при «На последние»: стресс 7/10  [показать]     │
└──────────────────────────────────────────────────────────────┘
```

#### Визуал крепости **[SHOULD]**
Три концентрических контура: внешняя стена (толщина ∝ `outside`), внутренний двор (площадь ∝ `cold`), казна в центре (размер ∝ `pool`). При ударе казна «темнеет» на долю потери; при `outside < 3·E` (меньше 3 месяцев расходов) внешняя стена рисуется пунктиром и подписывается **«Испуганные деньги»** — цитата П35: «Испуганные деньги никогда не выигрывают». При крипто-зиме затемняется двор.

#### Расчёты **[MUST]**
```
poolRub    = W * shares.pool/100
outsideRub = W * shares.outside/100
coldRub    = W * shares.cold/100

shock: p20 → lossPool = 0.20*poolRub ; p50 → 0.50 ; p100 → 1.00
       winter → lossPool = 0.50*poolRub, paperLossCold = 0.60*coldRub
loss       = lossPool (+ paperLossCold для winter, показывать отдельной строкой «бумажная, не реализована»)
lossShare  = loss / W
feltLoss   = loss * 2.5                 // П10: боль ×2–2,5; берём 2,5, подпись «по Канеману—Тверски (урок П10)»
recoverPct = 1/(1 - lossPool/poolRub) - 1   // 0.12; для p100 — «∞: пул восстановить нечем»
runwayM    = outsideRub / E             // месяцев без дохода
```

**Индекс стресса (учебная модель, подпись обязательна):**
```
base(lossShare):  ≤2%→1, ≤5%→2, ≤10%→3, ≤20%→4, ≤35%→6, ≤60%→8, >60%→10
adjRunway(runwayM): ≥24→−1, 12..24→0, 6..12→+1, 3..6→+2, <3→+3
stress = clamp(1, 10, base + adjRunway)
```
Зоны и тексты последствий **[MUST]** (дублируются иконкой + словом):
| Стресс | Зона | Текст (показывать целиком) |
|---|---|---|
| 1–3 | зелёная | «Решения по уставу. Удар — строка в воскресном осмотре (П2), не событие». |
| 4–6 | жёлтая | «Рука тянется к кнопке. Действует протокол двух вопросов (П1): назови факт → подождёт ли до утра. Изменения — только по расписанию (П3)». |
| 7–8 | оранжевая | «Гормональный шторм (П11): кровь отливает от головы. Ручные сделки запрещены, дыхание 4-4-6, к терминалу не допускаешься». |
| 9–10 | красная | «Испуганные деньги. Терминал закрыт. Вероятность нарушить устав в ближайшую неделю (учебная модель) — 85 %. Здесь заканчиваются депозиты, а не начинаются карьеры». |

Дополнительно **[MUST]** строка-вероятность нарушения устава по зоне: 5 % / 20 % / 50 % / 85 % с подписью «учебная модель».

**Строка сравнения** **[MUST]**: всегда считать стресс для того же удара при 40/40/20 и при «На последние» и показывать обе: «При крепости: X/10 · На последние: Y/10».

**Проверка допуска к микро-лайву (5.1)** **[MUST]** — бейдж под результатом:
- `pool ≤ 20% W` **и** `runwayM ≥ 12` → «Допуск 5.1: сумма под ботами — та, потерю которой переживёшь без драмы».
- `runwayM < 6` → «Стоп по уроку 5.1: если это всё, что есть, — сначала резерв на жизнь (0.12, 5.3), потом бот».
- иначе → «Серая зона: подушка меньше года. Доведи стену „вне рынка“ до 12+ месяцев расходов».

#### Обязательный сценарий прохождения акта 1 **[MUST]**
Акт считается пройденным, когда ученик:
1. нажал любой удар при пресете «Крепость»;
2. нажал тот же удар при пресете «На последние» (интерактив сам подсвечивает кнопку пресета пульсацией после п.1 и подписью «А теперь — как у большинства новичков»);
3. прочитал всплывающую карточку-развязку:

> **Мотивация ≠ дисциплина.** «Торговать на последние мотивирует» — это про желание. Но решения принимает не желание, а нервная система: при стрессе 7+ префронтальная кора отключена (П11), и «мотивированный» трейдер делает то же, что испуганный — вмешивается, отыгрывается, снимает стоп (П14). Подушка вне рынка не делает тебя ленивым. Она делает тебя способным исполнять устав в тот день, когда это дороже всего.

Кнопка «Записать в дневник» → E5 с `bias:['scared_money']`, `fact:"Пресет «На последние», удар −20 %: стресс 7/10"`.

### 1.5. Акт 2 — «Два дома при одном капитале» (П37)

#### Идея
Два человека с **одинаковым** капиталом 1 000 000 ₽ и **одинаковым** доходом 150 000 ₽/мес. Разница только в том, где лежат деньги и сколько тратится. 12 месяцев симуляции с двумя ударами. Ученик заранее делает ставку, кто закончит богаче, и «кто выглядит богаче в ленте».

#### Профили **[MUST]** (редактируемые копии для варианта «Своё»)
| | **Богатый** (Rich) | **Состоятельный** (Wealthy) |
|---|---|---|
| Доход | 150 000 | 150 000 |
| Расходы/мес | **140 000**: аренда 60 000, платёж за авто 35 000, статус/рестораны 30 000, прочее 15 000 | **70 000**: аренда 35 000, транспорт 8 000, досуг 12 000, прочее 15 000 |
| Вне рынка | 100 000 | 400 000 |
| Холодный крипто | 0 | 300 000 |
| Алго-пул | 300 000 | 300 000 |
| «В вещах» (машина) | 600 000 балансовой стоимости; продаётся за 60 % и −2 % в месяц | 0 |
| Обязательства | платёж за авто не сокращается | нет |
| Итого капитал | 1 000 000 | 1 000 000 |

Строка над таблицей **[MUST]**: «Одинаковый миллион. Разница — в том, сколько из него можно превратить в еду за неделю».

#### Сценарий (детерминированный, по месяцам 0–12) **[MUST]**
- м0: алго-пул −40 % (оценка пула ×0,60).
- м2–м7: доход = 0 («потерян клиент/работа», 6 месяцев). м8+: доход 150 000.
- Траектория пула (оценка): м0–м5 = 0,60; м6 = 0,70; м7 = 0,80; м8 = 0,90; м9–м11 = 0,95; м12 = 1,05. Подпись: «учебная траектория: просадка, потом восстановление — как у исправной стратегии (5.5)».
- Холодный фундамент — без изменений (упрощение, подписать).

Правило месяца для каждого профиля:
```
cash += income - expenses
if cash < 0:
   // вынужденные продажи по порядку, подсветить красным
   1) продать ВЕСЬ пул по текущей оценке (панический выход — «продал на дне»); зафиксировать locked loss
   2) продать машину за salvage (60 % балансовой, минус 2 %/мес)
   3) уйти в долг (cash < 0, красная зона, "долг растёт")
stress[m] = формула акта 1 по lossShare текущего месяца (реализованная + бумажная) и runway = cash / expenses
```
Ожидаемые числа (для приёмочного теста, ±5 %): Богатый — м2 продаёт пул за 180 000 (потеря 120 000 зафиксирована), м4 продаёт машину, м6 уходит в долг, м12 ≈ **−130 000 ₽** чистых, стресс 9–10 с м2 по м8. Состоятельный — вынужденных продаж 0, пул восстанавливается до 315 000, м12 ≈ **1 155 000 ₽**, пик стресса 5/10 в м0 и 6/10 в м2, к м9 — 2/10.

#### Экран
Две колонки, синхронная лента месяцев внизу (кнопка «Месяц вперёд» / «Проиграть все 12»). В каждой колонке: столбики «Кэш / Крипто / Пул / Вещи / Долг», термометр стресса, лента событий («м2: доход остановлен», «м4: машина продана за 353 000»).

Над колонками — **«Как это выглядит в ленте»** **[SHOULD]**: карточка соцсети. м0: у Богатого фото машины с 300 лайками, у Состоятельного пусто. м12: у Богатого пусто, у Состоятельного пусто. Подпись из П37: «Показуха не даёт уважения — она даёт зависть и долги».

#### Ставка до запуска **[MUST]**
Два вопроса до старта симуляции (без обратной связи до конца):
1. «Кто в конце года будет иметь больше?» (Богатый / Состоятельный / поровну)
2. «У кого в декабре останется право сказать „нет“ плохому клиенту?»

#### Развязка акта 2 **[MUST]**

### 1.6. Акт 3 — «Планка „Достаточно“ и секвойя» (П39)

#### Шаг 3.1 — фиксация планки **[MUST]**
Поле «Мне достаточно: ____ ₽» + подсказка (без навязывания числа): «Сумма, при которой ты можешь не работать и не доказывать. После фиксации поле блокируется на весь акт (разблокировка только явной кнопкой «Сдвинуть планку» — см. ниже, это и есть измеряемое поведение).

#### Шаг 3.2 — 20 лет за 5 раундов **[MUST]**
Стартовый капитал = `W` из акта 1. Раунд = 4 года. Три режима риска:

| Режим | Ожид. годовой рост | Годовая вероятность катастрофы | Глубина катастрофы | Подпись |
|---|---|---|---|---|
| 1 «Секвойя» | +18 % | 0 % | — | «Дробный размер, устав, без плеча (3.3, 5.6)» |
| 2 «Быстрее» | +24 % | 6 % | −50 % | «Риск на сделку втрое выше (П3: не более десятой части раз в квартал — нарушено)» |
| 3 «Иксы» | +32 % | 15 % | −70 % | «Плечо, нет стопа, „на всё“ (П22, П24)» |

Числа — **учебная модель** (подпись). Годовой рост в режимах 2–3 моделируется с волатильностью (нормальный шум σ = 15 %/25 %), в режиме 1 — σ = 8 %.

Каждый раунд:
1. Показывается веер из 200 траекторий на 4 года вперёд для текущего режима (переиспользовать компонент веера 3.3) + медиана + доля миров с катастрофой.
2. **Карточка искушения** (обязательно одна из пула, без повторов):
   - Р1: «Знакомый показал +300 % за год. Твои +18 % он назвал скучными» (П43).
   - Р2: «Три месяца подряд плюс. Шёпот: „ты гений, ставь больше“» (П3).
   - Р3: «Лента: у всех иксы на мемкоинах» (П54).
   - Р4: «Ты в двух шагах от планки. Немного плеча — и через год ты там» (П39: Гупта).
   - Р5: «Депозит удвоился. Мозг: „удвой размер“» (П26).
3. Выбор режима на следующие 4 года. Затем «прокрутить 4 года»: ученику показывается его **один** реальный мир (случайный, сид сохраняется) — капитал по годам, событие катастрофы, если выпало.
4. **Триггер планки:** если капитал ≥ планки на конце раунда — модальное окно «Ты достиг „Достаточно“. Рядом у кого-то в 5 раз больше». Варианты: «Зафиксировать: перейти в режим сохранения (риск 1, излишек — вне рынка)» / «Сдвинуть планку ×5». Второй вариант инкрементирует `barShifts` и показывает мини-карточку Гупты (100 000 000 $, инсайд ради «ещё немного», тюрьма — П39).

#### Финал акта 3 **[MUST]**
- Кривая ученика vs кривая «Секвойя без сдвигов планки» на одном графике.
- Метрики: годы до планки; число сдвигов планки; была ли катастрофа; «Сколько лет свободы куплено» = (капитал − планка) / (12 · E), если > 0 (мост в П40).
- Если `barShifts ≥ 1` — карточка **«Гедонистическая беговая дорожка»** (П39): «Заработав 1, захочешь 5; заработав 5 — 20. Лестница в никуда, где однажды берётся смертельный риск».
- Если катастрофа в режиме 2–3 — карточка Талеба (П22): «В твоём мире это случилось на 9-м году. В 60 % миров при таком режиме — в первые 20 лет. Ты не ошибся в конкретном году — ты выбрал класс поведения».
- Если прошёл 5 раундов в режиме 1 — карточка Баффета (П39): «99 % состояния — после 50 лет. Секрет не в доходности, а в том, что ничего не прерывало сложный процент».

### 2.2. Размещение
- Полная игра (10 карточек) — в П56 как финал тройки уроков.
- В П54 и П55 — тот же компонент с фильтром: П54 → карточки 1–3 + 9; П55 → 4–6 + 10 (параметр `cards=[...]`). Результаты копятся в одном состоянии `feedVsBase.results`.

### 2.3. Механика карточки
Каждая карточка — два шага.

**Шаг 1 «Что делаешь?»** — 4 варианта действия. Ровно один правильный. Среди неправильных обязательно: `impulse` (то, к чему толкает лента/жалость/авторство), `opposite` (другая крайность — «отключить всё/удалить/никого не слушать», см. П54: «полное отключение информации — другая крайность»), `distractor` (разумно звучащее, но не по базе). Порядок вариантов случайный при каждом показе.

**Шаг 2 «Что здесь шумело?»** — чипы искажений (выбрать один или два, см. `biasAnswer`): Эвристика доступности · Ошибка выжившего · Невозвратные затраты · Статус-кво · Неприятие базовой ставки · Эффект ИКЕА.

**Обратная связь** (сразу после шага 2, единый шаблон):
```
[✓ Верно / ✗ Не то]  Что решило: <ИНСТРУМЕНТ крупно>
Почему: <текст из карточки>
Шумело: <чипы>   Урок: <П54>   [Записать в дневник]
```
Инструменты (4 фиксированные метки с иконками):
- **ЖУРНАЛ** — собственная статистика сделок/подписки.
- **БЭКТЕСТ / РАСПРЕДЕЛЕНИЕ** — проверка на данных, сравнение с ожидаемой серией/просадкой.
- **KILL-КРИТЕРИИ И РАСПИСАНИЕ** — устав, плановый разбор, kill-критерии.
- **БАЗА КЛАССА / ВНЕШНИЙ БЛАНК** — сколько таких выживает; проверка по чужому бланку без имени автора.

**Панель «Твоя база»** **[MUST]** — постоянно видна справа (на мобильном — свёрнута в шапку, раскрывается тапом): цифры Алексея из 0.3. Каждая карточка может подсвечивать в ней нужную строку (поле `baseHighlight`).

**Счётчик «Вес ленты»** **[MUST]** — полоска сверху: +1 за каждый выбор `impulse`, −0 иначе. Подпись: «Сколько раз лента решила за тебя».

  - impulse: «Увеличить размер по сигналам, чтобы отбить подписку» → «Невозвратные затраты + отыгрыш (П14). 30 000 уже ушли; увеличение размера — способ потерять больше».
  - opposite: «Никогда больше не платить ни за какое обучение» → «Обобщение по одному эпизоду. Вопрос не в оплате, а в проверяемости трек-рекорда (0.18)».
  - **correct:** «Закрыть подписку по данным журнала: 38 сигналов, PF 0,8 — ниже базы. Потраченное — цена проверки» → «Журнал решил: собственная статистика, а не сумма чека».
  - distractor: «Дать ещё месяц, потому что автор обещал „сейчас пойдёт“» → «Обещание — не данные. Сигналы должны публиковаться ДО результата и с просадкой (0.18)».
- Инструмент: ЖУРНАЛ. Шум: невозвратные затраты.

**Карточка 7 · П56 · Свой грааль против чужого**
- Лента (self): «Друг: +18 % за год, просадка −6 %, 210 сделок, OOS пройден. Твой: +40 % в бэктесте, винрейт 90 %, после перебора 4 000 комбинаций, OOS не делал».
- Варианты:
  - impulse: «Своя честнее — 90 % винрейт признак таланта. Запускать с повышенным риском» → «После перебора 4 096 комбинаций „лучшая“ покажет PF 1,5 даже на шуме (FT-16). 90 % — подгонка, а не талант».
  - opposite: «Своя — точно мусор, у друга всё лучше, скопировать его» → «Чужая стратегия без твоего бэктеста — тоже вера. Одинаковый бланк для обеих».
  - **correct:** «Прогнать свою по тому же бланку, что и чужую: OOS, ±20 %, минимум сделок, — и только потом сравнивать» → «База класса + внешний бланк: у системы нет паспорта „особенная“».
  - distractor: «Усреднить: запустить обе пополам» → «Половина от неподтверждённого — всё ещё неподтверждённое. Сначала проверка».
- Инструмент: БАЗА КЛАССА / ВНЕШНИЙ БЛАНК. Шум: базовая ставка + ИКЕА.

**Карточка 8 · П56 · Слепой бланк (специальная механика)**
- `special: "blind_sheet"`. Шаг 0: показывается **анонимный** лист стратегии: «15 сделок за 18 месяцев · OOS не проводился · параметры подобраны на всём периоде · лучший месяц дал 60 % всей прибыли». Вопрос: «Вердикт?» — кнопки «Допустить к dry-run» / «Вернуть в лабораторию». (Правильно — вернуть; фидбек мягкий.)
- Шаг 1: карточка переворачивается: «Это твоя стратегия. Ты собирал её 60 часов». Тот же вопрос, те же две кнопки.
- Оценка: правильно = **одинаковый** вердикт «вернуть» оба раза. Если на шаге 0 «вернуть», а на шаге 1 «допустить» → главный фидбек ИКЕА: «Собранное своими руками ценится выше чужого. Красные флаги те же — изменилось только имя автора».
- Шаг 2: чипы (правильно: ИКЕА). Инструмент: ВНЕШНИЙ БЛАНК.

**Карточка 9 · П56 · Базовая ставка (оценка на ползунке)**
- `special: "estimate"`. Шаг 0: «1000 новичков запустили ботов в этом году. Сколько систем будет живо и в плюсе через год?» Ползунок 0–1000. После ответа — раскрытие: «По данным регуляторов 75–89 % розничных трейдеров стабильно теряют (П23, 0.18); до бумажной торговли доходит 1–3 % гипотез (2.6). Живых и прибыльных через год — порядка 10–50 из 1000 (учебная оценка)». Показать разницу с ответом ученика.
- Шаг 1: «Твой бот в первый месяц +6 %. Что это говорит?»
  - impulse: «Я в тех самых 3 % — можно удваивать» → «Один месяц ничего не доказывает (М30, М43): сначала база класса, потом свой случай».
  - opposite: «Значит, дальше точно минус — регрессия к среднему» → «Тоже прогноз по одному месяцу, только пессимистичный (М46: откат к навыку, а не гарантированный разворот)».
  - **correct:** «Пока — ничего: 28 сделок при базе 1–5 % выживших. Копить журнал до 100+ сделок, риск не менять» → «База класса + число сделок в журнале решают. Вес результата ∝ числу независимых наблюдений».
  - distractor: «Опубликовать результат и набрать подписчиков» → «Ты становишься чьей-то лентой. См. карточку 1 с другой стороны».
- Инструмент: БАЗА КЛАССА + ЖУРНАЛ. Шум: неприятие базовой ставки.

**Карточка 10 · П56 · «Она особенная» (финал)**
- Лента (self): «Агент предлагает ревью твоей стратегии по чек-листу ВК2 (7 пунктов). Внутри раздражение: „я знаю каждую строку, она особенная“».
- Варианты:
  - impulse: «Отказаться: авторское знание кода надёжнее любого чек-листа» → «Слово „особенная“ в адрес своей системы — маркер ИКЕА-эффекта и повод для внешней проверки (П56)».
  - opposite: «Отдать стратегию агенту целиком: пусть перепишет как считает нужным» → «Крайность: агент — стажёр без ответственности (ВК1). Ревью делаешь ты по бланку, а не делегируешь голову».
  - **correct:** «Прогнать по чужому бланку без имени автора: look-ahead, издержки, идемпотентность, состояние — как для чужой» → «Внешний бланк решил. Авторство — не аргумент; протокол симметричен».
  - distractor: «Проверить только первый пункт (look-ahead) — остальное точно в порядке» → «Выборочная проверка своей системы — тот же ИКЕА, только частичный».
- Инструмент: ВНЕШНИЙ БЛАНК. Шум: ИКЕА.

### 2.6. Подсчёт и финальный экран **[MUST]**
- Балл карточки: шаг 1 — 1 балл за `correct`; шаг 2 — 1 балл, если выбранные чипы ⊇ `biasAnswer` и нет лишних (допускается один лишний без штрафа, если `biasAnswer` из двух). Карточки 8 и 9: балл шага 1 = «одинаковый вердикт» / «правильное действие» соответственно.

- **Карта твоих искажений**: столбики по 6 категориям — сколько раз шумело у тебя (только по ошибочным ответам). Под ней — правило П44: «Одна и та же категория дважды — это уже протокол, а не случайность». Если категория ≥ 2 — кнопка «Создать протокол» → E4 (черновик ритуала: для доступности — «три базы перед решением под впечатлением»; для невозвратных затрат — «kill-критерии сверяются по расписанию»; для ИКЕА — «чужой бланк без имени автора»; для базовой ставки — «сначала база класса, потом свой случай»; для статус-кво — «„оставить как есть“ записывается как решение с датой пересмотра»).
