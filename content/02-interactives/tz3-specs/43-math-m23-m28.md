# ТЗ на три интерактива Матфакультатива: М23/М24, М25/М27, М28

Ниже — три детальные спецификации для агента-разработчика. Сначала общий блок (обязателен для всех трёх), затем по одной спеке на интерактив. Все тексты интерфейса — на русском; английские обозначения допускаются только внутри подсказок «Ткни в непонятное».

---

## 0. Общие требования ко всем трём интерактивам

### 0.1. Методические инварианты
1. **Один интерактив — одно заблуждение.** Оно записано в паспорте и должно быть «сломано» конкретным экраном (помечен `⚑ ключевой момент`).
2. **Числа берутся из текста урока.** Константы вынесены в `config`, рядом — комментарий, из какого урока взято число. Менять их без правки комментария нельзя.
3. **Сквозной герой — Алексей** (депозит 1000 $ / 100 000 ₽, бот из Py-14).
4. **Кнопка «показать формулу»** по умолчанию выключена. Новичок сначала видит картинку и слова, формула — по запросу.
5. **Языковой слой «Ткни в непонятное»:** любой греческий/латинский символ (μ, σ, √n, x̄, SE, IQR, skew) — кликабельный чип → всплывашка на русском (2 строки + пример). Словарь общий, см. §0.4.
6. **Критерий освоения** фиксируется телеметрией (§0.5), а не «досмотрел до конца».

### 0.2. Общие компоненты (сделать один раз, переиспользовать)
| Компонент | Назначение | Где используется |
|---|---|---|
| `SeededRNG` | mulberry32 + Box–Muller (нормальное) + Student-t (толстые хвосты) через нормаль/χ² | все три |
| `Stats` | `mean, median, std(ddof=1), quantile(p, linear), trimmedMean(k), skew, excessKurtosis, iqrFences()` | все три |
| `Histogram` | канвас/SVG, bins-слайдер, оверлеи вертикальных линий, штриховка ±1σ, наложение кривой нормали, drill-down по столбцу (клик → список наблюдений) | 1 (шаг 1), 3 |
| `NumberLineFan` | «веер» точек/штрихов на числовой оси с подписями | 1 |
| `DecisionModal` | модалка с вопросом, карточками улик и вариантами ответа + запись в журнал | 2 |
| `StatCards` | карточки «Среднее / Медиана / σ / …» с анимацией изменения числа (200 мс) | все три |
| `TermTip` | «Ткни в непонятное» | все три |
| `JournalWriter` | адаптер к движку E5 (`journal.append({lesson, type, payload})`); если E5 ещё нет — localStorage `journal.<lesson>` | 2, 3 |

Технически: TypeScript, без внешних графических библиотек (или та, что уже используется в приложении — уточнить у автора). Один файл-модуль на интерактив: `sim_m23_population.ts`, `sim_m25_outlier.ts`, `viz_m28_histogram.ts`.

### 0.3. Дизайн и доступность
- Палитра дальтоник-безопасная: среднее — оранжевый `#E07A1F`, медиана — синий `#2F6FDB`, истинное μ — зелёный `#1E9E5A`, выброс — фиолетовый `#8E44AD`. Плюс форма маркера (ромб/круг/треугольник), не только цвет.
- Все кнопки доступны с клавиатуры; слайдеры — `<input type=range>` с `aria-valuetext` на русском («выборка из 100 сделок»).
- Мобильная вёрстка: панели в столбик, графики не уже 320 px, таблицы прокручиваются горизонтально.
- Анимации ≤ 400 мс, отключаются при `prefers-reduced-motion`.

### 0.4. Словарь «Ткни в непонятное» (минимум)
| Токен | Русское имя | Подсказка |
|---|---|---|
| μ | истинное среднее | «Среднее по ВСЕЙ совокупности — по всем сделкам, которые стратегия сделает когда-либо. Его никто не видит, его оценивают.» |
| x̄ | выборочное среднее | «Среднее по тем сделкам, которые у тебя есть. Меняется от выборки к выборке.» |
| σ | сигма, разброс | «Насколько типичная сделка отклоняется от среднего.» (ссылка М9) |
| σ/√n, SE | стандартная ошибка | «Насколько прыгает выборочное среднее. Вчетверо больше сделок — вдвое меньше прыжок.» (М30) |
| медиана | серединное значение | «Половина сделок лучше, половина хуже. На неё одна огромная сделка почти не влияет.» (М26) |
| IQR | межквартильный размах | «Ширина „средних 50 %“ сделок. Правило 1,5·IQR ищет кандидатов в выбросы.» (М26) |
| skew | перекос | «В какую сторону хвост длиннее.» (М29) |
| kurtosis | толщина хвостов | «Как часто случаются очень большие результаты по сравнению с „колокольчиком“.» (М29, 1.2) |

### 0.5. Телеметрия (единый формат)
```ts
track(event: string, payload: {sim: 'm23'|'m25'|'m28', step: string, ...})
```
Обязательные события: `sim_open`, `step_enter`, `answer` (с полями `correct`, `attempt`), `mastery` (когда выполнен критерий освоения), `sim_close` (с `durationSec`). Для М25 дополнительно `decision` по каждому кейсу.

## 1. М23/М24 — СИМ «Одна совокупность, 20 выборок»

### 1.1. Паспорт
- **Уроки:** М23 «Генеральная совокупность и выборка», М24 «Параметр и оценка». Единый интерактив, встраивается после блока «Глубже» урока М24; из урока М23 — ссылка-кнопка «Прожить: одна совокупность, 20 выборок» после «Итога».
- **Тип:** СИМ (симуляция с управляемыми шагами).
- **Ломаемое заблуждение:** «500 сделок — это вся реальность» (история стратегии = истина о ней).
- **Учебный результат:** ученик умеет объяснить словами: «моё среднее по 500 сделкам — одна из возможных оценок; типичный разброс таких оценок ≈ σ/√n; следующие 500 сделок — новая выборка».
- **Время:** 6–8 минут.
- **Связи:** М10 (закон больших чисел), М30 (стандартная ошибка), М31 (интервал), 1.9 (out-of-sample), FT-09 (сколько сделок нужно).
- **Отношение к существующим симам** «Выборка из скрытой совокупности» (М23) и «Разные выборки — разные оценки» (М24): новый интерактив поглощает их сценарии в шагах 1–2; уникальная ценность — шаги 3 и 5. Рекомендация автору: оставить в уроках только новый интерактив, старые пометить как устаревшие.

### 1.2. Данные и константы
```ts
const CFG = {
  mu: 8.0,          // М24: «собрали 100 наблюдений и получили среднее 8%»; истинное μ = 8.0 (блок «Глубже»)
  sigma: 20.0,      // М24, «Глубже»: sd = 20.0
  unit: '% на сделку', // единица из текста М24
  nOptions: [10, 30, 100, 500, 2000],
  nDefault: 100,    // М24: 100 наблюдений
  samplesCount: 20, // название интерактива
  historyN: 500,    // М23: «500 исторических сделок»
  ciZ: 1.96,
  seedDefault: 2024
};
```
- Совокупность по умолчанию: нормальное распределение N(μ, σ). Переключатель «рынок с толстыми хвостами» (шаг 3, свёрнутая опция «Глубже»): Student-t с df = 3, масштабированное так, чтобы σ = 20 (масштаб = 20/√3).
- Все выборки генерируются `SeededRNG(seed)`; кнопка «новый набор выборок» меняет seed. Seed показывается мелким шрифтом («набор № 2024») — для воспроизводимости при разборе с преподавателем.

### 1.3. Компоновка экрана
```

```
Мобильный: панели в столбик, веер средних — всегда виден при прокрутке (sticky-полоса высотой 90 px).

### 1.4. Сценарий (state machine)

**Шаг 1 — «Одна выборка».**
- Подзаголовок: «У Алексея есть история: 100 сделок бота. Какой у стратегии истинный средний результат?»
- Кнопка `Взять выборку из 100 сделок` → анимация: из тумана «высыпаются» 100 точек в гистограмму (300 мс), появляется оранжевый ромб x̄ на оси.
- Появляется форма оценки: «Твоя оценка μ: [x̄ предзаполнено] от [ ] до [ ]». Поля «от/до» пустые, обязательны. Подсказка: «Насколько ты уверен? Задай коридор.»
- Сохраняем `guess = {point, lo, hi}`. Переход к шагу 2 только после ввода.

**Шаг 2 — «Двадцать исследователей».**
- Подзаголовок: «Представь 20 Алексеев. У каждого — своя история из 100 сделок той же стратегии.»
- Кнопка `Ещё 19 выборок` → последовательно (120 мс на выборку) на правой панели пробегают мини-гистограммы (последняя остаётся), а на веере накапливаются 20 ромбов x̄₁…x̄₂₀.
- Строка обратной связи (числа подставляются): «20 честных исследователей, одна стратегия, одни правила — и 20 разных ответов: от {min} до {max}. Разброс их средних — {sdMeans} (стандартное отклонение по 20 значениям).»
- Карточка (появляется при «показать формулу»): «Ожидаемый разброс средних: σ/√n = 20/√100 = 2,0. Получилось: {sdMeans}.»

**Шаг 3 — «Больше сделок — уже веер».**
- Слайдер n ∈ {10, 30, 100, 500, 2000}. При каждом изменении: 20 выборок пересчитываются, веер перерисовывается (плавно 300 мс), под веером — таблица, текущая строка подсвечена:

| n | σ/√n | Коридор 95 % (±1,96·σ/√n) |
|---|---|---|
| 10 | 6,32 | ±12,4 |
| 30 | 3,65 | ±7,2 |
| 100 | 2,00 | ±3,9 |
| 500 | 0,89 | ±1,8 |
| 2000 | 0,45 | ±0,9 |

- Обратная связь при переходе 100 → 500: «В 5 раз больше сделок — разброс сузился только в √5 ≈ 2,2 раза. Чтобы сузить вдвое, нужно вчетверо больше сделок.»
- Опция «Глубже» (свёрнута): переключатель `рынок с толстыми хвостами` → та же таблица, но фактический sdMeans при малых n заметно больше формулы; подпись: «Формула считает, что редкие огромные сделки не случаются. В крипте случаются (урок 1.2) — сделок нужно ещё больше.»

**Шаг 4 — «Открываем совокупность».** `⚑ ключевой момент № 1`
- Кнопка `Открыть μ` → туман рассеивается, на веере зелёная вертикаль μ = 8,0 и зелёная полоса ±1,96·σ/√n для текущего n.
- Автоподсчёт: «Из 20 средних в зелёную полосу попало {k} — примерно так и должно быть (19 из 20).»
- Проверка оценки из шага 1 (три ветки):
  - коридор ученика уже 2·SE → «Ты был уверен в {point} ± {half}. Честный коридор при 100 сделках — ±3,9. Твоя уверенность была в {ratio} раза больше, чем позволяют данные.»
  - коридор ≥ 2·SE и содержит μ → «Твой коридор накрыл μ. Заметь: он был широким — это и есть честность при 100 сделках.»
  - коридор не накрыл μ → «Коридор промахнулся. Это не позор: даже честные интервалы промахиваются в 1 случае из 20 (М31). Вопрос — был ли он достаточно широким: {да/нет}.»

**Шаг 5 — «Будущее — тоже выборка».** `⚑ ключевой момент № 2 (главный)`
- Подзаголовок: «У Алексея 500 исторических сделок, среднее {xHist}. Он решил: „это и есть результат стратегии“.»
- Левая панель: карточка «История: 500 сделок, x̄ = {xHist}». Кнопка `Прожить следующие 500 сделок` — при нажатии из совокупности берётся новая выборка n = 500, появляется карточка «Будущее № 1: x̄ = {x1}», разница подсвечена. Кнопку можно нажать до 5 раз, карточки выстраиваются в ряд; на веере — точки «история» (серая) и «будущее» (оранжевые).
- Обратная связь после 2-го нажатия: «Два будущих отличаются от истории на {d1} и {d2}. Типичная разница двух средних по 500 сделок — σ·√(2/500) ≈ 1,26. История — не реальность. История — одна из выборок из реальности, и следующие 500 сделок — другая.»
- Обязательный вопрос (одиночный выбор, засчитывается критерий освоения):
  «Стратегия показала среднее +8,7 на 500 исторических сделках. Что это?»
  - а) «Истинный результат стратегии — она приносит 8,7» ✗
  - б) «Одна из оценок истинного среднего с типичной ошибкой около ±0,9; следующие 500 сделок дадут другое число» ✓
  - в) «Ничего не значит, 500 сделок — мало» ✗ (обратная связь: «500 сделок — не мало и не много. Это n со своей ошибкой σ/√n ≈ 0,9. Вопрос не в „много/мало“, а в размере коридора.»)
  - г) «Гарантия, что среднее не опустится ниже 8» ✗
- После ответа — итоговая карточка: «Три вещи, которые ты теперь знаешь» (текст ниже) + ссылки на М30, М31, 1.9.

Итоговая карточка (текст):
1. «Есть μ — истинное среднее. Его никто не видит.»
2. «Есть x̄ — то, что ты посчитал по своим сделкам. Оно прыгает; размер прыжка ≈ σ/√n.»
3. «Твоя история — одна выборка. Будущее — следующая. Между ними — не ошибка, а нормальный разброс.»

### 1.5. Алгоритмы
```ts
function drawSample(rng, n, dist) {                 // dist: 'normal' | 'fat'
  const xs = new Float64Array(n);
  for (let i=0;i<n;i++) xs[i] = dist==='normal'
      ? CFG.mu + CFG.sigma*rng.normal()
      : CFG.mu + (CFG.sigma/Math.sqrt(3))*rng.studentT(3);
  return xs;
}
function fan(rng, n, k=20, dist) {
  const means = []; for (let j=0;j<k;j++) means.push(Stats.mean(drawSample(rng,n,dist)));
  return { means, sdMeans: Stats.std(means), se: CFG.sigma/Math.sqrt(n) };
}
```
Ось веера: фиксированный диапазон [μ−15, μ+15] на всех шагах, чтобы сужение веера при росте n было видно без перемасштабирования. При n = 10 часть точек может выйти за край — рисовать стрелку «→ +18,3» у края.

### 1.6. Критерий освоения и телеметрия
- `mastery` = верный ответ (б) на шаге 5 с первой или второй попытки **и** ≥ 2 нажатия «Прожить следующие 500».
- Дополнительная метрика для автора: `guess_overconfidence = (2*SE)/(hi-lo)` из шага 1 — доля учеников с коэффициентом > 1 должна падать при повторном прохождении.

### 1.7. Приёмочные тесты
1. При seed = 2024, n = 100, dist = normal: `sdMeans` ∈ [1,3; 2,8] (20 значений, допустимый разброс); при n = 2000 — ∈ [0,25; 0,7].
2. Таблица шага 3 совпадает с числами выше с точностью 0,01.
3. Шаг 5 недоступен, пока не открыт μ (шаг 4); вопрос недоступен, пока не сделано ≥ 1 «будущее».
4. Все токены μ, σ, √n, x̄ имеют TermTip; клик по ним открывает подсказку с клавиатуры (Enter).
5. При `prefers-reduced-motion` выборки появляются мгновенно, состояние идентично.

### 1.8. Вопросы автору

## 2. М25/М27 — СИМ «Один выброс на 5000»

### 2.1. Паспорт
- **Уроки:** М25 «Почему среднее может обманывать», М27 «Выбросы: ошибка или реальность?». Один интерактив; в М25 встраивается после «Глубже» (экран А), в М27 — тот же интерактив открывается сразу на экране Б (deep-link `?start=B`).
- **Тип:** СИМ + ИГР (симуляция с игровым протоколом решения).
- **Ломаемое заблуждение:** «Необычное = ошибка» (а значит, его можно удалить, чтобы статистика стала „правильнее“). Побочное: «среднее описывает типичную сделку».
- **Учебный результат:** ученик (1) видит, что среднее ломается одной точкой, а медиана нет; (2) перед кнопкой «удалить» проверяет источник значения и различает ошибку данных, ошибку единицы измерения и настоящее рыночное событие; (3) понимает, что удаление реального события делает риск-метрики ложными.
- **Время:** 8–10 минут.
- **Связи:** М5 (тот же ряд чисел), М26 (правило 1,5·IQR), М29 (хвосты), 2.6 (чек-лист данных: выбросы > 10σ проверяются вручную), FAI-06 (политика выбросов), П24 (индейка), 3.6 (крах-дни).
- **Отношение к существующим:** «Ползунок выброса» (М25) — экран А его заменяет; «Удалить, оставить или проверить?» (М27) — экран Б его развивает в банк кейсов с уликами.

### 2.2. Данные и константы
```ts
const BASE = [100, -50, 20, -30, 60];   // М5, «Глубже»: pnl = [100,-50,20,-30,60], среднее 20
const OUTLIER = 5000;                    // М5: pnl[-1] = 5000 → среднее ≈1008, медиана 20
const UNIT = '₽';                        // М5 считает в рублях
// Экран Б, 50 сделок Алексея: генерируются детерминированно (seed 5027) так, чтобы:
//   mean ≈ +20, median ≈ +18, std ≈ 45, min ≥ -110, max ≤ 130  (проверить тестом)
```
Проверочные значения экрана А (тест): без выброса — среднее 20, медиана 20, усечённое (без min и max) 30; с выбросом — среднее 1008, медиана 20, усечённое 30; правило 1,5·IQR: Q1 = −30, Q3 = 100, IQR = 130, верхняя граница 295 → 5000 помечен.

### 2.3. Экран А — «Что случилось со средним» (М25)
Компоновка: слева таблица 5 сделок (№, результат), справа три `StatCards`: **Среднее** (оранжевый), **Медиана** (синий), **Усечённое среднее** (серый, с подсказкой «отрезали лучшую и худшую сделку»). Снизу — «весы»: горизонтальная ось с 5 точками и треугольником-опорой под средним.

Механика:
1. Переключатель над таблицей: `Последняя сделка: 60 ⇄ 5000`. При переводе на 5000:
   - точка улетает вправо за край оси (анимация, стрелка «→ 5000»);
   - опора весов (среднее) ползёт с 20 к 1008 (число на карточке «пробегает» 20 → 1008 за 600 мс);
   - карточка медианы вздрагивает и остаётся 20; усечённое — остаётся 30.
   - строка: «Одна сделка из пяти сдвинула среднее в 50 раз. Медиана не заметила. Какое из трёх чисел описывает твою обычную сделку?»
2. Вопрос-клик: «Какая цифра пойдёт в отчёт как „типичная сделка“?» — три кнопки-карточки. Правильно: медиана (или усечённое — принимается с комментарием). При выборе среднего: «В отчёте будет „+1008 ₽ на сделку“. Четыре сделки из пяти были в диапазоне −50…+100. Это реклама, а не описание.»
3. Кнопка `Показать хитрость отчёта` (необязательно): рядом появляются два бейджа «среднее +1008 / медиана +20» и подпись из урока: «Связка „среднее много, медиана мало“ честно намекает: весь результат сделали одна-две сделки.»
4. Кнопка `Дальше: а что делать с этой сделкой?` → экран Б.

### 2.4. Экран Б — «Кнопка, которая спрашивает» (М27) `⚑ ключевой момент`

**Б0 — Политика выбросов (30 секунд, обязательный шаг).**
Три радиокнопки-карточки: «Как ты будешь поступать с необычными сделками?»
- П1 «Удаляю всё, что дальше 3σ от среднего — это шум»
- П2 «Ничего не трогаю — данные есть данные»
- П3 «Смотрю источник: ошибку данных исправляю, рыночное событие оставляю»
Выбор запоминается (`policyChosen`), без оценки «правильно/неправильно» — оценка придёт в конце.

**Б1 — Серия Алексея (50 сделок).**
Гистограмма 50 сделок + `StatCards` (среднее, медиана, σ, худшая сделка, макс. просадка серии). На гистограмме подсвечена одна точка-кандидат (по правилу 1,5·IQR). Большая красная кнопка **«Удалить выброс»**.

При нажатии кнопка **не удаляет**, а открывает `DecisionModal`:
> «Стоп. Это ошибка данных или рынок? Пока не знаешь — не трогай. Проверь улики.»

**Б2 — Кейс с уликами.** Модалка содержит:
- Значение: «Сделка № {id}: {value} ₽»
- 4–5 карточек-улик (закрыты; открытие каждой — клик; открытых улик ≥ 2 требует система перед решением):
  1. **Строка журнала бота** (сырой лог: время, цена входа, цена выхода, объём)
  2. **Свеча того дня** (мини-график OHLC + объём) с подписью даты
  3. **Другие пары в тот час** (BTC, ETH: изменение %)
  4. **Сообщения биржи/статус** («технические работы», «нет данных»)
  5. **Соседние записи журнала** (есть ли дубль, совпадение id)
- Четыре кнопки решения (из списка М27): **Удалить** · **Исправить →** (выпадающий: «сдвиг запятой ÷100», «убрать дубль», «пересчитать комиссию», «другое: [поле]») · **Оставить** · **Проверить ещё** (открывает следующую улику; стоимость — «время», счётчик в углу; не влияет на оценку).

**Банк кейсов (6 штук; порядок фиксирован, значения — из генератора):**

| № | Название | Значение | Улики говорят | Истина | Верное действие | Что покажет неверное |
|---|---|---|---|---|---|---|
| 1 | «Запятая уехала» | +5000 | В логе цена выхода 6 720 000 при свече с максимумом 67 200; объём нормальный; другие пары ±0,5 % | Ошибка единицы (×100) | Исправить ÷100 → +50 | Удалить: «Ты стёр честную сделку +50 вместо того, чтобы починить запятую» |

**Б3 — Цена красоты (финал).**
Две колонки: «Честная история» (все верные решения) и «История по твоим решениям». Показать те же метрики + один расчёт: «Размер позиции по правилу риска 1 % (урок 3.3 / 4.4) при твоей σ и худшей сделке: {size_yours} vs честный {size_true}. Разница — на столько ты бы недооценил риск.» Если ученик удалил кейс 3 или 6: красная плашка «Стратегия по твоим данным выглядит на {x} % спокойнее, чем она есть».
Затем оценка политики из Б0: «Твоя политика была „{П}“. На этих кейсах она бы: удалила {a} реальных событий, оставила {b} ошибок данных. Политика П3 — единственная, которая не врёт в обе стороны.» + ссылка на FAI-06.

Итоговый вопрос (критерий освоения): «В журнале сделок есть −5000 ₽ при обычном размере −50. Первое действие?» — а) удалить ✗; б) оставить не глядя ✗; в) открыть лог и свечу того дня, найти причину ✓; г) заменить на среднее ✗.

### 2.5. Алгоритмы и правила
- Кандидат в выбросы: `Stats.iqrFences(xs, 1.5)` (М26). Показывать не «выброс», а «кандидат — нужно проверить».
- Генератор 50 сделок: смесь 80 % N(20, 25) + 20 % N(−10, 35), клип [−110, 130]; кейсовые значения подставляются на фиксированные позиции (например, № 7, 19, 23, 31, 38, 44).
- Макс. просадка серии: кумулятивная сумма pnl, `max(peak − cur)`.
- Размер позиции для Б3: `size = 0.01 * deposit / |worstTradeRel|`, где `worstTradeRel = worstTrade / typicalStake` (typicalStake = 650 $ ≈ 0,01 BTC, из Py-14); формулу показать по кнопке.

### 2.6. Тексты обратной связи (общие)
- При попытке решить, открыв < 2 улик: «Ты решаешь, не посмотрев. Открой хотя бы лог и свечу.»
- При верном «Оставить» реального события: «Да. Необычное — не значит ошибка. Этот день — часть риска, а не мусор.»
- При верном «Исправить»: «Ошибка данных лечится исправлением, а не удалением: сделка была, просто записана криво.»

### 2.7. Телеметрия и приёмка
- `decision` на каждый кейс: `{case, decision, correct, evidenceOpened, secondsSpent}`.
- `mastery` = верный итоговый вопрос **и** ≥ 4 из 6 кейсов решены верно **и** кейс 3 или 6 не удалён.
- Тесты: числа экрана А (см. 2.2); кнопка «Удалить» никогда не изменяет массив без прохождения модалки; при удалении кейса 3 в Б3 обязательно появляется красная плашка; журнал получает 6 записей.

## 3. М28 — ВИЗ «Гистограмма моих сделок»

### 3.1. Паспорт
- **Урок:** М28 «Распределение результатов». Встраивается после «Глубже» (после кода с `np.histogram`). Существующий сим «Формы распределений» остаётся как теоретический; новый — про **свои** данные.
- **Тип:** ВИЗ (интерактивная визуализация с drill-down).
- **Ломаемое заблуждение:** «Средняя описывает стратегию».
- **Учебный результат:** ученик по своей серии сделок отвечает на пять вопросов урока (центр, разброс, хвост, необычные значения, симметрия) числами и словами и видит, где среднее прячет правду.
- **Время:** 5–7 минут (+ повторные заходы с новыми данными).
- **Связи:** Py-14 (источник данных), М25/М26 (медиана, квантили), М29 (skew/kurtosis — принимает данные отсюда), 1.2 (толстые хвосты), FT-14/FT-15 (разбор причин выхода и форензика).

### 3.2. Источники данных (провайдеры, по приоритету)
Интерактив принимает `pnl: number[]` (₽ или $, единица передаётся отдельно). Провайдеры:

Если в Py-14 сохранение ещё не реализовано — **это часть данного ТЗ** (добавить 5 строк в Py-14). Если сделок < 30 → показать режим «Почему по 5 сделкам гистограмма не строится» (столбики по одному наблюдению, подпись: «У Алексея за неделю {n} сделок. Гистограмма начинает что-то говорить от 30, уверенно — от 100. Ниже — та же стратегия на 52 неделях»), и автоматически предложить провайдер 2.

   - 18 % N(−18, 8) — обычные убытки;

   Ожидаемо: среднее ≈ +0,8 $, медиана ≈ +4 $, худшая ≈ −70 $, 5 %-квантиль ≈ −60 $, доля > 0 ≈ 65 %, перекос отрицательный. **Это и есть сюжет:** «средняя почти ноль — а типичная сделка +4: куда делись деньги? В шесть процентов стопов». Единица — $.

### 3.4. Сценарий

**Открытие — режим «Только среднее».** `⚑ ключевой момент`
При первом открытии гистограмма скрыта: на пустой оси одна оранжевая палка «Среднее: +0,8 $» и подпись «Так стратегию видит тот, кто смотрит только на среднее». Кнопка `Показать все сделки` → палка «рассыпается» в гистограмму (анимация 500 мс). Подпись меняется: «А так она выглядит на самом деле. Среднее стоит здесь — а большинство сделок вот здесь.» Синяя линия медианы появляется второй, с подписью расстояния между ними.

**Пять вопросов (правая панель).** Каждый вопрос — карточка с тремя состояниями: закрыта → ученик выбирает вариант ответа глядя на гистограмму → раскрывается число и объяснение. Варианты и правильные ответы вычисляются из данных (не захардкожены):
1. **Где центр?** Варианты: «около среднего ({mean})», «около медианы ({median})», «они совпадают». Правило: если |mean − median| > 0,25·σ → верно «около медианы» с пояснением «Центр — там, где горб. Среднее утянули редкие сделки.»
2. **Насколько широко?** Показывается ±1σ штриховкой; вопрос: «Какая доля сделок внутри полосы?» Варианты 50 % / 68 % / 90 %; ответ — фактическая доля; пояснение с оговоркой: «У колокольчика было бы 68 %. У тебя {p} %.»
3. **Есть ли длинный хвост?** Варианты «слева (убытки)», «справа (прибыли)», «нет». Правило: сравнить |Q05 − median| и |Q95 − median|; если разница > 30 % → хвост в сторону большего. Пояснение: «Худшие 5 % сделок в среднем {cvar05}; лучшие 5 % — {cvar95}.»
4. **Необычные значения?** Показать кандидатов по 1,5·IQR (подсветка столбцов фиолетовым, счётчик). Вопрос: «Что с ними делать?» — единственный верный: «Открыть и проверить (М27)». Клик по столбцу открывает список сделок (drill-down): № сделки, вход, выход, результат — с кнопкой «Разобрать в М27» (deep-link на экран Б с этим значением, если провайдер = alexey52; иначе просто ссылка на урок).
5. **Симметрично?** Варианты «да / перекос влево / перекос вправо». Правило: sample skew < −0,3 → влево, > 0,3 → вправо, иначе симметрично. Пояснение: «Число, которое это измеряет, — перекос (skew). Про него — следующий урок М29. Твоё значение уже посчитано: {skew}.»

После пяти ответов — плашка: «Что среднее не сказало о твоей стратегии» — автосводка из 3 строк, собранная из ответов (пример для alexey52): «Среднее +0,8 $ выглядело как „почти ноль“. На деле: типичная сделка +4 $, 6 % сделок — стопы по −65 $, они и съедают результат. Это не „слабая стратегия“, это стратегия с конкретным хвостом — и с ним можно работать (ссылка FT-14: причины выхода).»

**Таблица чисел** (сворачиваемая, все названия по-русски, английские — в TermTip):
n · среднее · медиана · усечённое среднее (10 %) · σ · мин · макс · квантили 5 / 25 / 75 / 95 % · доля прибыльных · средний плюс · средний минус · перекос · толщина хвостов (избыточная, по Фишеру; примечание из 1.2 про конвенции) · «доля общей прибыли, которую дали лучшие 5 % сделок» · «доля общего убытка от худших 5 %».

**Вкладка «Сравни с…».** Выбор пресета того же среднего (+2 $) → вторая гистограмма полупрозрачно поверх. Подпись: «Одно среднее — три разные жизни. Какую из них ты выдержишь — вопрос урока М29 и 0.15.»

**Кнопки действий:**
- `В журнал` — запись `{lesson:'M28', source, n, stats, answers}` через `JournalWriter`.
- `Передать в М29 →` — `appStore.set('m28.pnl', {pnl, unit, source})`; урок М29 читает и открывает на этих данных.
- `Наложить нормаль ⋯` — пунктирная кривая N(mean, σ), масштабированная под площадь гистограммы; подпись: «Если бы сделки были „колокольчиком“. Считай, сколько столбиков торчит за пунктиром в хвостах.»

### 3.5. Алгоритмы
- Бины: равной ширины по диапазону [min, max], число по слайдеру; при n < 30 — режим «один столбик = одно наблюдение» (dot-plot).
- Нормаль поверх: `y(x) = n·binWidth·pdf(x; mean, σ)`.
- Skew (выборочный): `m3/m2^1.5`; избыточный эксцесс: `m4/m2² − 3`; при n < 30 не показывать (прочерк с подсказкой «мало данных»).
- Drill-down: столбец хранит индексы наблюдений; список сортируется по |pnl|.
