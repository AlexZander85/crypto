## Ключевые технические требования (общие для обеих поставок)

- Контент (сценарии E1, профили E2, кейсы E6, фикстуры, словари) — **в JSON-файлах контента, не в коде компонентов**; линтер контента в CI (Приложение А, п.5).
- Vanilla JS, без сетевых вызовов, детерминизм из seed, адаптив ≥360px, клавиатурная навигация, `glossary.json` — общий.
- Числа — только из текстов уроков; unverifiable — `"verified": false`.
- IndexedDB (E5), экспорт JSON/Markdown; события телеметрии — единый формат `onEvent`.
- Порядок сборки: Glossary/TouchToKnow/LangSwitch/Journal hook → E1 → E2 → мост E2↔E1 → контент (Приложение А).
