## Контракт (кратко; полный — ТЗ-2 §2)

- Регистрация: `window.EXPERT_WIDGETS[id] = function(box){…}` — один ключ на файл
  (идентификаторы = существующие id виджетов в приложении, менять нельзя).
- vanilla JS ES2017, Canvas 2D / inline SVG, тёмная тема через CSS-переменные
  с фолбэками (`--txt`, `--mut`, `--acc2`, `--ok`, `--bad`, `--warn`, `--line`, `--mono`).
- `mulberry32(seed)` для учебных сценариев; «новый раунд» — seed из `Date.now()`.
- Чистота повторного рендера: таймеры/rAF/resize снимаются в первых строках каждой
  функции (паттерн `box._expTimers` / `box._expRaf` / `box._expCleanup` / `box._expRO`).
- Адаптив от 360px, без внешних зависимостей, без `alert/confirm/prompt`.
- Артефакт — в `box.dataset.artifact` / `box._artifact` + событие `expert:artifact`
  (bubbles; у части виджетов — `exp:artifact`/`expert-artifact`, варианты см. в коде).

## Спец-факты для интегратора

1. **W-03 / W-13 — двойная поставка.** В fable_viget.md каждая пришла дважды:
   ранние версии (L5019 / L5493) отменены поздними (L6072 / L6463 — «Два автомата»,
   «Переобучение» с артефактом attempts/solved). В файлах — поздние.
2. **W-35 — критический фикс сборки (единственный, оправдан ТЗ-2 §9).** У эксперта
   `fit(); newRound(seed);` — первый `draw()` читает `coins[k]` до инициализации →
   TypeError при готовом layout. Исправлен порядок на `newRound(seed); fit();`
   (файл помечен комментарием). Вернуть эксперту списком замечаний.
3. **W-39 — три id на одну функцию.** Если в уроке 0.19 сейчас три контейнера —
   оставить один, два других отрисуют тот же детектив (рекомендация эксперта,
   fable_viget.md «Что учесть при встраивании»).
4. **Артефакты.** События встречаются трёх видов: `expert:artifact` (большинство),
   `exp:artifact`, `expert-artifact`; данные — в `detail` или `box.dataset.artifact`.
   Диспетчеру достаточно слушать все три имени на `document` (bubbles: true).
5. **Диспетчер-патч (T-4.7):** перед штатным рендером виджета приложение проверяет
   `window.EXPERT_WIDGETS[id]` — при наличии вызывает экспертовскую версию вместо
   текущей. Откат — исключить файл из сборки. A/B — по одному виджету.
6. **Байтовая точность файлов.** Извлечение — посимвольная копия из fable_viget.md
   (без правок, кроме фикса W-35). Все `[m]`-индексы (`out[m]`, `freq[m]`, `streak[m]`)
   в файлах целы — проверено численно (`out[m]`: 2, `freq[m]`: 3, `streak[m]`: 1,
   битых `c.out]`: 0) и `node --check`. ⚠️ Предостережение: при ручном копировании
   кода из .md через интерфейсы с markdown-рендерингом последовательности вида
   `[m]` могут «съедаться» (квалифицируются как ссылки) — код брать только из
   этих .js-файлов, не из md.
