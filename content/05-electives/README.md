## Ключевые решения эксперта (шпаргалка сборщика)

- **РФ-трек:** три колонки-метки 🟢 переносится / 🟡 меняется / 🔴 «похоже, но иначе» на каждый урок;
  центральный урок Р9 «Ставка как гравитация» (бенчмарк — ключевая ставка, не индекс);
  Freqtrade к MOEX из коробки не подключается (Р13 — проверка правила 1.6 «код один, адаптеры меняются»);
  5 ступеней прогрессии с выходными артефактами; 4+2 РФ-ритуала E4; сквозная арка дневника Алексея.
  Нумерация: Р — рынок РФ, О — опционы, В — валюта. Адаптер к брокеру — вне трека (микро-лайв).
- **Контур жизни:** «не рантье, а оператор с зарплатой»; стоп-лист трека: «пассивный доход», «жить на проценты»,
  «финансовая независимость»; страны/банки/школы — только категориями (А/Б/В); три уровня тревоги семьи;
  «Семейный устав оператора» — отдельный документ со вторым подписантом; три «тяжёлых» интерактива (#4/#6/#15)
  — один общий движок «пошаговая симуляция с событиями и двумя шкалами»; конструктор устава — движок 5.6.
- **Мосты между треками:** Р15 (валютный риск, рублёвая жизнь) ↔ Ж-трек (В3 → ТЗ-9); вместе треки закрывают
  арку «выпускник → оператор в среде РФ → жизнь с капитала».
