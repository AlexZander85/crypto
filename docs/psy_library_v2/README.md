# 📚 Библиотека Психологии и Риск-Инженерии v2 (Deep Case-Study Edition)
## Институциональная база знаний для Квант-Архитектора и AI-Ментора

Данная папка содержит **15 глубоких практических руководств** по фундаментальным трудам мировой литературы трейдинга, нейробиологии, теории вероятностей и поведенческой экономики.

### 🌟 Структура каждого конспекта v2:
1. **🏛️ Бэкграунд автора:** Практический опыт (банки, проп-дески, фонды), реальные объемы капитала.
2. **🧠 Ключевые концепции и формулы:** Теоретический базис и математический аппарат.
3. **💥 Реальные кейсы и драмы из практики:** Истории сливов, триумфов и разборов ошибок трейдеров.
4. **🛠️ Пошаговые протоколы и ранбуки:** Чек-листы и алгоритмы действий для внедрения в торговый устав.
5. **🎯 Триггеры и диагностические маркеры для AI-Ментора (RAG):** По каким фразам и паттернам ментор определяет проблему ученика и предлагает решение.
