## Как открыть
Просто открой `index_v12.6.html` в браузере (всё локально, без сервера). Кнопка **«🎓»** в шапке приложения — хаб «Моё обучение». Кнопка **«💬 Наставник»** в футере каждого шага (и «💬» в шапке плеера) открывает наставника с контекстом текущего шага; на финале урока при ≥3 неверных попытках квиза (счётчик сохраняется между сессиями) появляется рекомендация адаптивной тренировки. `Ctrl+K` из плеера — поиск по курсу.
