## Как открыть
Просто открой `index_v12.9.html` в браузере (всё локально, без сервера). Кнопка **«🎓»** в шапке — хаб «Моё обучение» (секция «🕘 Недавние тесты» — быстрый доступ к последним тестам). Кнопка **«💬 Наставник»** в футере шага открывает наставника с контекстом шага; **в тестовом режиме** наставник знает, какой тест и порция открыты («Наставник видит тест: … · вопросы 6–10»). Действие «🧑‍🏫 Проверка Фейнмана» работает из любого места: плеер сам перейдёт на шаг Фейнмана, а если поле недоступно — ввод появится прямо в панели. На финале урока и на экране результата теста при накопленных ошибках (счётчик сохраняется между сессиями) появляется рекомендация адаптивной тренировки. В конспекте — «⬇ Скачать файлом (.md)»; кнопка «🚀 Перейти: <симулятор>» открывает практикум внутри плеера (Esc — вернуться к уроку). На шаге Фейнмана — «🤖 Спросить Наставника: понятно ли я объяснил?». Тап по заблокированной кнопке «Завершить урок» показывает подсказку «🔒 Сначала сдайте квиз» (и на mobile). После сдачи выпускного экзамена сертификат открывается на экране результата, «Перейти к достижениям» закрывает плеер и открывает вкладку прогресса. Спидран-таймер фазовых тестов продолжает идти после перезагрузки страницы. `Ctrl+K` из плеера — поиск по курсу.

## Красные линии (соблюдены во всех этапах)
Контент (уроки, банки, глоссарий) заморожен — дампы 14/14 секций идентичны во всех версиях; `ADAPTIVE_QUESTION_BANK` не тронут (§11.9). Этапы 1–4 и 6–7 — только аддитивные вставки. Принцип Э6: внутренний контент урока не покидает Learn Player, если интеграция технически возможна (симуляторы — оверлеем; особенно значимо для Академии Freqtrade). Этап 5 по решению владельца продукта дополнительно содержит 12 локальных правок кода ридера (закрывают находки №1, 2, 6, 7, 13 из реестра Э4) — каждая помечена комментарием `№…` и откатывается по списку из §3 отчёта Э5.
