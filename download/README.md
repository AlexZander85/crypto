## Как открыть
Просто открой `index_v12.5.html` в браузере (всё локально, без сервера). Кнопка **«🎓»** в шапке приложения — хаб «Моё обучение»: продолжить урок/попытку, программа курса, прогресс, тесты, карточки, конспект. `Ctrl+K` из плеера — поиск по курсу.

## Красные линии (соблюдены во всех этапах)
Контент (уроки, банки, глоссарий) заморожен — патч только добавляет UI-слой поверх (2 блока `learn_player_css/js`), ноль правок существующих функций в Этапе 3.
