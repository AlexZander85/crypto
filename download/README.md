## Как открыть
Просто открой `index_v12.7.html` в браузере (всё локально, без сервера). Кнопка **«🎓»** в шапке — хаб «Моё обучение» (секция «🕘 Недавние тесты» — быстрый доступ к последним тестам). Кнопка **«💬 Наставник»** в футере шага открывает наставника с контекстом шага; на финале урока и на экране результата теста при накопленных ошибках (счётчик сохраняется между сессиями) появляется рекомендация адаптивной тренировки. В конспекте — «⬇ Скачать файлом (.md)». Спидран-таймер фазовых тестов продолжает идти после перезагрузки страницы. `Ctrl+K` из плеера — поиск по курсу.

## Красные линии (соблюдены во всех этапах)
Контент (уроки, банки, глоссарий) заморожен — дампы 14/14 секций идентичны во всех версиях; `ADAPTIVE_QUESTION_BANK` не тронут (§11.9). Этапы 1–4 — только аддитивные вставки. Этап 5 по решению владельца продукта дополнительно содержит 12 локальных правок кода ридера (закрывают находки №1, 2, 6, 7, 13 из реестра Э4) — каждая помечена комментарием `№…` и откатывается по списку из §3 отчёта Э5.
