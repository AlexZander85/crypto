## 6. «Найдено в коде (не тронуто)»

1. **«Холостой» вызов `offerMistakeClassification` в `checkPhaseTestNumeric`** (возврат игнорируется) — существующая особенность; при неверном числовом ответе журнальный блок не показывается (в отличие от опционных вопросов, где обёртка 36447 дописывает его в `ptest_exp_*`).
2. **Дубль PSY_CUM в p8 (202 = 160+21+21)** — заморожено; плеер берёт рантайм-массив как есть.
3. **Отсутствие поверхности literacy/psy_cum** (A16) — реализовано как диагностика, ключи гейтов не пишутся.
4. **`mathTestState.correct` — лучшая попытка (Math.max), а `passed` — по последней** — семантика `finishMathTest` сохранена без изменений (см. паритет 7/10 после 8/10).
5. **`answerMathTest` перерисовывает подложку фазы 7 (A19)** — под плеером скрыто и безвредно; обёртки Этапа 1 идемпотентны.
6. **`window.mathTestState` (28472) может отставать от лексического `let mathTestState`** при импорте прогресса — плеер читает только лексическое имя.
7. **Спидран-ghost от resume** — после перезагрузки `_ptStart` выставляется заново (старый UI попытки не персистит вовсе — паритета нет, известная грань).
8. Отсутствующие `assets/infographics/img-*.jpg` (1 `ERR_FILE_NOT_FOUND` на прогоне) — комплектация, graceful degradation ридера.

## 8. Известные ограничения и предложения в Этап 3

1. **Один слот черновика** `cn_learn_test`: открытие другого теста заменяет незавершённую попытку без предупреждения (паритет: смена чипа вкладки «Тесты» делает то же сегодня; отмечено в §9 плана).
2. **Мат-пересдача** показывает «отвечено N/M» по отметкам текущей попытки; `mathTestState.answers` при этом содержит прежние ответы до их перезаписи — визуально вопрос может быть уже «отвечен» прошлой попыткой (семантика сменяемости; паритет со старым UI, где явного сброса нет).
3. **Порядок подсчёта**: «отвечено X из N» для мат-тестов — по черновику плеера, результат — только по кнопке сдачи (требование «плеер считает только свой черновик» соблюдено).
4. **Разделитель накопительного блока** показывается один раз за попытку (перед первым `_cumulative`-вопросом) — паритет со старым UI; при resume после порции с разделителем он может не показаться снова.
5. **Баннер главной** обновляется при перерисовке `renderDailyQuests` (как и баннер Этапа 1); в Этапе 3 Learn Home заберёт эту роль.
6. **Предложения в Этап 3**: блок «Тесты и экзамены» в Learn Home (состояния всех 13 банков уже формирует `bankMeta()`); якорь прогресса тестов; перенос пикера 🏁 в хаб; «недавние» для тестов; конспект/поиск — по ТЗ §12.
