## 1. Сводка

- **P1 — встроенные практикумы.** Утверждён принцип: *«Внутренний контент урока не должен покидать Learn Player, если интеграция технически возможна»*; зафиксирован в README и комментарии модуля с отдельной оговоркой про Академию Freqtrade (лабы ft* уже внутренние — копирование команд и ТЗ без переходов; все будущие практикумы Академии обязаны встраиваться в плеер). Реализовано на главном нарушителе: CTA обложки урока «🚀 Перейти: <симулятор>» (`LearnPlayer._goSim`, 42 сим-ссылки фаз 0–5) больше не закрывает плеер — симулятор открывается **оверлеем внутри плеера** (`learn-overlay[data-ov="lp6sim"]`): узел `#sim_<id>` переносится из подложки приложения в оверлей **DOM-переносом** (без клонов и дублей id — слушатели и состояние сохраняются), штатные инициализаторы `showSim()` запускаются до переноса. При закрытии (✕, Esc, клик по фону, закрытие плеера, переключение режима) узел возвращается на прежнее место — подложка приложения не деградирует. Фолбэк на прежний контур (закрыть плеер → вкладка «Тренажёры») сохранён только для отсутствующих боксов. Проба подтвердила: у всех 42 simId есть свои `#sim_*` боксы — интеграция технически возможна для всех ссылок.
- **P2 — accessibility фокуса.** Проверено пробой на v12.7: initial focus (openPlayer/openTestWindow фокусируют «✕», хаб — поле поиска) и return focus (`closePlayer` → `S.entryEl`) **уже работали**; недостающее добавлено: **`aria-modal="true"`** на корне плеера (buildRoot — общий для урока и теста) и корне хаба (Home); закрыт краевой случай возврата фокуса при входе «из ридера»: closePlayer переоткрывает ридер, прежняя точка входа могла оставаться валидным узлом, но семантически устареть (например, кнопка «🎓» шапки под модалом) — теперь при `readerWasOpen` фокус всегда получает переоткрытый модал ридера. Оверлей практикума — самостоятельный диалог (`role="dialog"`, `aria-modal`, фокус на «✕» при открытии, возврат в шаг урока при закрытии).
- **P3 — ИИ-верификация Фейнмана.** В контуре наставника v10 уже существовал экшен **`feynman`** (`MENTOR.ask('feynman', lessonId, {explanation})` → вердикт `understood/partial/missed` + `advice` + `gaps`; мок честно помечен «ДЕМО», ДЕФ-22) и готовый рендер **`window.mentorF1`** (лимит 30/день, фильтр запрещённых фраз, сохранение в `cn_feynman_ai`) — но на шаге Фейнмана он не был размещён. Кнопка «🤖 Спросить Наставника: понятно ли я объяснил?» добавлена в `renderFeynmanBox` (V2 — общий бокс ридера и плеера) и вызывает **существующий** `mentorF1` — код наставника не тронут. Пустой/короткий ввод (<10 символов) — вежливая подсказка, вызов не расходуется.
- **Объём диффа:** +19 строк CSS и +290 строк JS (модуль `learn_player_stage6`) — ровно 2 аддитивные вставки, правок 0. Новых LS-ключей нет (`cn_feynman_ai` — существующий v10-ключ; `mentor_cache_*` — существующий кэш наставника). Артефакт: `index_v12.8.html` (v12.7 + Этап 6).

## 2. Ключевые проектные решения

1. **DOM-перенос вместо клонирования.** Симуляторы — статические боксы `#sim_<id>` с живыми обработчиками; `appendChild` в оверлей сохраняет слушатели и инлайн-состояние, а возврат узла восстанавливает подложку. Клонирование дало бы дубль id и развал инициализации — исключено по построению (приёмка: `boxUnique === 1` на всех путях).
2. **Все пути закрытия покрыты одной точкой.** Э1 удаляет оверлеи через `closeOverlays()` и корень через `closePlayer()`; обе функции обёрнуты с восстановлением узла ПЕРЕД удалением — практикум не может «уйти» вместе с корнем плеера ни при Esc, ни при крестике, ни при переключении в тест/карточки (приёмка 4: закрытие плеера при открытом практикуме — бокс возвращён).
3. **Фолбэк честного паритета.** Если бокс симулятора отсутствует или плеер не открыт, `_goSim` ведёт себя ровно как в Э1 (закрыть плеер → `goToLessonSim`) — принцип применяется только там, где интеграция технически возможна, формулировка заказчика соблюдена буквально.
4. **P3 — проводка, а не новый ИИ-контур.** Экшен `feynman` и рендер `mentorF1` уже были в v10 (доступны обоим поверхностям через общий `renderFeynmanBox`); новое — кнопка и guard'ы ввода. Лимит 30/день общий с остальными действиями наставника; демо-вердикт помечен самим контуром (приёмка: «🎭 ДЕМО-вердикт…» в ответе).
5. **Фокус — дополнение, а не переделка.** Существующие механизмы Э1/Э3 сохранены; добавлены только недостающие атрибуты и краевые случаи — риск регрессии существующих сценариев клавиатуры минимален (регрессия 9/9 зелёная).

## 5. Принцип встроенных практикумов (зафиксирован)

> **«Внутренний контент урока не должен покидать Learn Player, если интеграция технически возможна.»**

- **Сейчас:** все 42 сим-ссылки уроков открываются внутри плеера; карточки, тесты, конспект, поиск, наставник — уже внутренние (Э1–Э5); лабы Академии Freqtrade (ft01–ft12: `ai_agent_task` с копированием ТЗ/команд, microRecall, таблицы) не содержат внешних переходов — проверено дампом блоков.
- **Freqtrade:** трек Академии — приоритетная зона принципа: практические работы исполняются в плеере (копирование команд в терминал ученика — штатный внутренний сценарий Э1); новые практикумы Академии (бэктест-лабы, конфиг-тренажёры) проектируются как инлайн-виджеты/оверлеи плеера по образцу Э6, без переходов во внешние поверхности приложения.
- **Исключение по формулировке:** интеграции, технически невозможной (например, полноценный внешний терминал Freqtrade), касается фолбэк-правило — прежнее поведение с явным закрытием плеера, а не «за спиной» ученика.

## 6. Известные ограничения

1. **Состояние симулятора** внутри оверлея живёт, пока оверлей открыт; повторное открытие переинициализирует симулятор штатным `showSim()` (то же происходит при повторном клике на чип в приложении — паритет).
2. **Сим-оверлей и переключение режима**: при переходе «урок → тест» практикум закрывается автоматически (узел возвращается в подложку) — осознанное решение против полузакрытых состояний.
3. **Фейнман-вердикт в mock-режиме** — правило «длина >40 символов», честно помечено самим контуром наставника (ДЕФ-22); в боевом режиме вердикт отдаёт endpoint, payload-контракт не менялся.
4. Унаследованные допущения приёмки сохраняются: `ERR_FILE_NOT_FOUND` (отсутствующие assets) и спорадическая гонка rAF/close Этапа 1 (правка запрещена дифф-контрактом Э1).
