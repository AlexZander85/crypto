## 2. Ключевые проектные решения

1. **Не править `rootClick` (P1-1).** Подстановка контекста делается обёрткой `mentorOpenPanel` сверху цепочки (Э7 → Э4 → v10-мост → v10): меньше поверхность отката, поведение идентично рекомендованному выражению. Панель в тест-режиме теперь показывает «Урок: p1» вместо «Урок: общий» и несёт карточку порции; для мат-тестов — «Урок: generic» + карточка «🧮 Мат-тест факультатива» (без диапазона порций как в рекомендациях). Диагностики показываются как «🔬 Диагностика».
2. **Переход на шаг Фейнмана — через публичный API (P1-2).** Внутренний `goTo(fi)` блокирует прыжок вперёд (`S.visited`), поэтому использован рекомендованный заказчиком `LearnPlayer.open(lid, idx)` — он же «точно на шаг» из Этапа 3 (без resume-диалога при явном idx).
3. **Два режима панельного поля (P1-2).** Если шаг Фейнмана отрисован в плеере — поле панели *связанное* (`lp7_feynman_in`): значение копируется в живой шаг с `dispatchEvent(new Event('input'))`, поэтому работают черновик Фейнмана и фильтр запрещённых слов. Если шага не видно (панель из хаба/чужого контекста) — поле создаётся **со штатным id** `feynman_input_<lid>` (id гарантированно свободен в этой ветке) и существующий `mentorF1` читает его сам — код вердикта/сохранения `cn_feynman_ai` не дублируется. Повторные «Проверить» при коротком тексте не пересобирают бокс (набранный текст и фокус сохраняются, растёт подсказка).
4. **Гейт — по состоянию, не по атрибуту (P2-4).** Первый вариант нормализатора («disabled → aria-disabled») имел дефект: повторный проход срывал `aria-disabled`, потому что ветка «кнопка включена» не отличала *разблокирована* от *готова*. Итоговый `lp7UnlockGates()` вычисляет заблокированность из состояния урока (`lessonsDone`, `lessonQuizPassed`, `lessonCheckState`, mastery-ветка) — идемпотентен при любом числе проходов. Точки нормализации: `renderStep`, `renderBottom`, `updateLessonCompleteBtn`, `openFullscreenLesson`, `handleLessonQuizAnswer` (последний включает кнопки напрямую, минуя `updateLessonCompleteBtn` — иначе оставался устаревший `aria-disabled`).
5. **Перенос флагов в цепочке обёрток.** Обёртка Э7 `mentorOpenPanel` затёрла флаг `__lp4wrapped` (selfTest Э4) — внедрён универсальный перенос собственных свойств предыдущего звена цепочки (`Object.keys(prev)`) для `mentorOpenPanel` и `mentorRun`. Правило зафиксировано для будущих этапов.
6. **Проверка факта перед кодом (P2-3).** Проба `probe7.js` на v12.8 до реализации: сертификат на экране плеера подтверждён; `S.lessonId` в тест-режиме = null (панель «Урок: общий»); v10-панель переваривает `testId` без крахов (13 действий, 0 ошибок) — что сделало подстановку безопасной.

## 5. Известные ограничения

1. **Устаревание карточки шага Э4 в панели.** Если после открытия панели плеер перешёл на другой шаг (в т.ч. автопереход Э7 на Фейнман), карточка шага Э4 показывает шаг, с которого панель открыта. Косметика, вне объёма Э7.
2. **Мат-тесты — контекст «generic».** Диапазон порций для мат-тестов не показывается (в карточке — тип и название банка), что соответствует формулировке рекомендации.
3. **mastery-уроки.** В текущем контенте блоки `mastery_check` не встречаются — ветка подсказки «Сначала подтвердите критерий приёмки» покрыта кодом-репликой, но не найдена в данных (проверена косвенно через state-логику `lp7GateLocked`).
4. **Печать сертификата из плеера.** Кнопка «🖨️ Распечатать» (`window.print()`) печатает текущий вид вместе с плеером — поведение v10 не менялось.
