## 4. Отклонения от литерала П2 (все — в пользу ТЗ, задокументированы)

1. **`trkPct()` терял ×100** — литерал П2 возвращал `Math.round(0.85)` = 1%. Исправлено: доля 0..1 → процент. (Найдено приёмкой C9: при полном ядре и 5 гейтах «Пройдено 1%».).
2. **Чип в тестовом режиме** — литерал показывал бы «🟠 факультатив» на экране теста (`S.lessonId = null`). Добавлен guard `TS.active` (§9.2: чип — только для уроков).
3. **`stage_completed`** — в литерале событие зависело от порядка (только в колбэке `lesson_complete` и требовало уже сданный гейт). Реализовано `trkStageEventsScan()` + обёртка `calcPhaseTestResult` (только слушает факт сдачи; запись результата не изменяется): событие детерминированно фиксирует «уроки + гейт», ровно одно на стадию (дедуп по журналу).
4. **`sprint_completed` одноразово** — литерал перезапускал событие при каждой сдаче электива после финиша Спринта. Добавлен guard по журналу.
5. **Сортировка предложений 🔥→⭐→💤** — литерал брал порядок массива П1 (на якоре 1.12: ⭐🔥⭐). §9.2 п.4 и §11-№12 требуют приоритетный порядок — добавлена стабильная сортировка перед cap.
6. **Cap предложений из `trkAB().offerCap`** — вместо жёсткой 3 (§14.5: эксперименты 1..3 без релиза).
7. **Тумблер «По треку/По фазам» в обоих видах** — литерал не давал вернуться из «По фазам» в Спринте (кнопка жила только в трек-виде).
8. **`CNTracks.upsell()` из окна плеера** — литерал вызывал `LearnPlayer.openHome()`, который блокируется при активном плеере (`if(S.active) return`). Исправлено: `_lp3ReturnHome = true; LearnPlayer.close()` — существующий контур Э3 переоткрывает хаб.
9. **Гейт-карточка стадии** — условие «последний урок стадии и её уроки пройдены» считается по core-урокам стадии (`s.lessons`), а не по `trkStageProgress` (который включает вплетённые П-уроки). Обоснование: чек-лист №13 — при пропущенном псих-минимуме гейт-CTA обязан быть доступен (soft-политика §9.4), псих-уроки возвращаются очередью `trkNext`. Статус «✅ сдан» в «Маршруте» по-прежнему считается честно (уроки+псих+гейт).
10. **Бейдж 🛡️ в панели** — §9.3 требует «🛡️» для псих-минимума; литерал давал им 🟢. Добавлено (якорь `coreStages[PSY].lessons`).
11. **`trkBlockMins` через `parseTimeEst`** — вместо `parseInt(L.timeEst)` (helper из скоупа плеера, §10.0-7; корректно для `minutes`-поля).
12. **`trkFinishAugment` guard `TS.active`** — тестовый режим не доходит до renderStep, добавлен защитно.
13. **Перенос собственных свойств вдоль цепочки обёрток** (правило Этапа 7) — для всех 7 обёрток (lp3HomeHtml, lp3NextUnpassed, lp3ProgramHtml, Home.open, updateChrome, renderStep, lp3MapProgram).
14. **Кнопки профиля/вида** — `primary/ghost` вместо несуществующего глобального класса `on` (`.on` в CSS скоупнут к `.learn-seg/.lp3-tabs`).

Найденные в П2 ошибки (№1, №2, №4, №7, №8, №9) — причины, по которым «копировать П2 дословно» было нельзя; ТЗ §10 прямо требует сверять имена и якоря с живым кодом.

## 5. Ключевые решения

- **Маршрут в обоих профилях** — в Архитекторе секция показывает карточку полного пути и кнопку возврата в Спринт (§9.1/§11-№9), стадии и % Спринта скрыты.
- **Очередь вплетённых уроков** — `trkNext` возвращает П-урок сразу после пройденного якоря (интерливинг §3); «Следующий по треку» при этом подписывается «🛡️ Обязательный псих-урок». Это же возвращает пропущенный псих-минимум перед следующей стадией.
- **Одноразовые вехи** — `sprint_completed` и `stage_completed` дедуплицируются по журналу `cn_track_events` (никаких новых ключей).
- **A/B-каркас** — `cn_track_ab` читается при каждом подсчёте предложений; по умолчанию `{cohort:'A', gatePolicy:'soft', offerCap:3}` (§14.5).
- **«Позже»** — persistent-dismissal (осознанное упрощение v2, §12-Р4); восстановление — `localStorage.cn_track_offers` или консоль `CNTracks.data`.
