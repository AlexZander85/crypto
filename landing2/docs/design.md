# Дизайн-система лендинга «КриптоНавигатор» — «Инженерный журнал» (v3)

История: v2 «Торговый терминал» (тёмная) → v3 «Бумажный журнал» по решению пользователя («дай новое лицо, не из палитры промта»). Тёмная сборка сохранена: `reports/backup-dark/`.

## Идея

Продукт уже говорит на бумажном языке: журнал когнитивных ошибок, письмо из будущего, устав оператора, разборы. Лендинг = **инженерный журнал кванта на миллиметровке**: тёплая бумага, чернила, красная ручка наставника, печати аттестации. Тёмные скриншоты приложения становятся «экспонатами» (РИС. 1…) — контраст «бумажная методика + живой терминал» и есть визуальная история продукта. Ни один крипто-лендинг рынка так не выглядит; эстетика спорит с неоновой индустрией — ровно как тон «мы не обещаем прибыль».

## 2. Типографика

- **H1/H2/H3 — Georgia (сериф, системный)**: «печатный журнал». H1 clamp(32→52px)/700.
- **Body** — системный гротеск 16px/1.6.
- **Данные (цены, цифры, метки) — mono** (Cascadia/Consolas): числа доверия, цены, подписи экспонатов, тикер.
- **Рукописный слой** — Georgia italic: цитаты Криптика, breath-абзацы, подпись письма, problem-closing.

## 3. Пространство и форма

Отступы 4/8/12/16/24/40/64; секции 96px (64 mobile); сетка 1080px. Радиусы 10/14. Тени — **жёсткие офсетные** `4px 4px 0 rgba(31,41,51,.12)` (печать/картон), только для карточек и кнопок; hover — сдвиг кнопки в сторону тени (тактильный «штамп»).

## 4. Сигнатурные элементы

1. **Бумажная телеграфная лента** под шапкой: бегущие котировки, пунктирные края, пометка `SYNTHETIC FEED`; пауза при reduced-motion.
2. **Печати**: `.stamp` — двойная рамка, поворот ±4–6°: «0 ₽ · навсегда» (синяя), «один раз. навсегда» (красная). Только факты.
3. **Красная ручка**: eyebrow-метки секций, подчёркивание-росчерк под акцентом H1 (SVG-волна), пунктирные разделители До→После.
4. **Экспонаты**: скриншоты в рамках `РИС. N · файл · размеры ●` — тёмный терминал на белой подложке с жёсткой тенью.
5. **Заметки на полях**: цитаты Криптика — Georgia italic на карточке с красной левой границей.
6. **Чернильные свечи**: разделители секций — детерминированные SVG-ряды свечей в ink-цветах (seed фиксирован).
7. **Чек-листы**: галочки — зелёный карандаш; чекбоксы согласия — красный акцент.
8. **Статус-строка футера**: `v7.0 · 2026-08 · 134/145/21/205`.

Правило меры: декор (`aria-hidden`, `user-select:none`) никогда не несёт смысла; движение отключается при reduced-motion.

## 5. Изображения

Только реальные скриншоты: 01-home (герой, fetchpriority=high), 05-psychology, 04-simulator, 03-lesson, 08-mobile; 09-trainer-demo.gif не используется в v3 (тёмный GIF выбивается из бумаги; решение пересмотреть при желании). Все `loading="lazy"` кроме героя, явные width/height (CLS=0).

## 6. Компоненты

Кнопки: primary — чернильная заливка + бумажный текст + офсетная тень; secondary — контур 1.5px. Модалка — бумажная карточка. Демо-стакан — единственный тёмный блок (экспонат терминала), цвета строк #4ADE80/#FB7185/#9AA7B8 на #141B26 (контраст проверен). FAQ — details/summary с «+» моно.

## 7. Анимации

Hover-переходы 150ms, бегущая лента 48s linear, мигание стакана 900ms (пауза вне вьюпорта), плавный скролл. `prefers-reduced-motion: reduce` отключает всё.
