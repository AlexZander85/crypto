## 1. Проект в двух абзацах

**«КриптоНавигатор»** — платный онлайн-курс по алготрейдингу криптовалют с симуляторами,
тренажёрами, AI-наставником «Криптик» и живым рыночным слоем. Продукт живёт как SaaS
(подписка, тарифы Демо/Лайт/Про/Макс; таргет — Cloudflare Workers, см. `saas/`), офлайн-копия
дистрибутируется одним HTML-файлом. Аудитория — русскоязычные новички; язык всего контента —
**русский**. Позиционирование: честность, ноль обещаний доходности, «не торгуй, пока не поймёшь».

**Текущая версия v15.1** — монолит `index_v15.1.html` (8 МБ, 93 274 строки, 225 уроков,
256 интерактивов, 77 типов блоков, 9 сюжетных симуляторов, Pyodide-песочница, Freqtrade).
Монолит стал непреодолимым порогом: каждая правка = python-хирургия, Grep по нему ненадёжен.
**Принято решение (ADR-001): пересборка v16** — конвейер `build.mjs` → `dist/index_v16.html`
с golden-паритетом 225/225 (Фаза 1), затем Vite SPA (Фаза 2, SaaS-таргет). **Внешний эксперт
контент закончил 2026-09-09 (все 11 ТЗ закрыты). Дальше работают только наши агенты.**

## 5. Правила работы агента (необсуждаемые)

1. **Язык — русский.** Все документы, код-комментарии к контенту, worklog — по-русски.
2. **Worklog:** перед стартом прочитай хвост `/home/z/my-project/worklog.md` (последние 2–3
   секции — что сделали предыдущие агенты). После работы ДОБАВЬ секцию в конец по шаблону:
   `---\nTask ID: <N>\nAgent: <имя>\nTask: <миссия>\nWork Log:\n- …\nStage Summary:\n- …`
   Ничего не перезаписывай, только добавляй.
3. **Скрипты:** любой код ≥10 строк — файлом в `/home/z/my-project/scripts/<имя>.py|.mjs`
   и запуск через bash; инлайн-скрипты запрещены. При ошибке — правь файл и перезапускай.
4. **Коммит и пуш:** после каждого транша/фазы. Сообщения по-русски, в духе
   «T-4.17: КП-1 и КП-2 собраны (30 из 57 вопросов)». Не оставляй незакоммиченных изменений
   к концу сессии. Ветка — main, репо — `/home/z/my-project/repo`.
5. **Чистота текста:** следи, чтобы в контент не проскакивали случайные CJK-символы и мусор
   (уже дважды ловили). Проверяй генерируемый текст сканером перед коммитом.
6. **Числа и факты:** ничего не выдумывать. Числа курса — только из текстов уроков/спек;
   канон чисел (55% / R 1.3 / риск 1% / серия 7–8 / $1000 / ED <10/10–25/>25 / 8 недель И ≥50
   сделок / 8–10 месяцев / 40/40/20-развод) — в `manifest/course-canon.json` (создаст сборщик)
   и должны совпадать во всех материалах.
7. **«Переезд и улучшение — никогда одновременно»** (ADR-001 §13.4-1): не улучшай то, что
   переносишь/компилируешь. Улучшения — отдельный шаг, отдельный коммит, с обоснованием.
8. **Границы (V16-FINAL-CONTENT-GAPS §Е):** никакого нового контента уроков сверх
   поставленного; без реальных имён брокеров/школ/API (только категории); без прогнозов
   ставок/тарифов (только плашки «проверить на дату» ⚑); дубли-поставки прежних волн не брать.
9. **Дубль-контроль:** прежде чем создать файл/сущность/движок/компонент — проверь, нет ли
   готового (карта, реестры, `_registry.json`, каталог сущностей от агента 05). Дублирование
   = дефект работы.
10. **Автономность:** действуй без вопросов к владельцу; спорные места решай по §4 и
    фиксируй решение в worklog/комментарии. Единственное основание остановиться —
    противоречие, которое нельзя разрешить §4 (тогда остановись и опиши конфликт).

## 6. Контракт виджета ТЗ-2 (для всех, кто пишет код интерактивов)

Полный текст — `content/02-interactives/widgets/README.md` (§ «Контракт») и
`content/02-interactives/expert-rebuild-contract.md`. Кратко:

- Регистрация: `window.EXPERT_WIDGETS[id] = function(box){…}` — один ключ на файл;
  vanilla JS ES2017; Canvas 2D / inline SVG; тёмная тема через CSS-переменные с фолбэками
  (`--txt, --mut, --acc2, --ok, --bad, --warn, --line, --mono`).
- Детерминизм: `mulberry32(seed)`; «новый раунд» — seed из `Date.now()`.
- Чистота повторного рендера: таймеры/rAF/resize снимаются в первых строках функции
  (`box._expTimers / _expRaf / _expCleanup / _expRO`).
- Адаптив от 360px; внешних зависимостей нет; `alert/confirm/prompt` запрещены.
- Артефакт урока: `box.dataset.artifact` / `box._artifact` + событие `expert:artifact`
  (bubbles; допустимы также `exp:artifact` / `expert-artifact`).
- 60 FPS (ADR-001 §13.4-5): анимации только `transform/opacity`; один rAF-луп на экран;
  `prefers-reduced-motion` уважать.
- Двигатели (E1–E8): `window.ENGINES.eN = { mount(box, instance, ctx) }`; инстансы — ТОЛЬКО
  JSON в `content/data/<движок>/*.json`; ctx общий: `glossary / journal / telemetry / rng / lang / save-load`.
- Приёмка: `node --check` + smoke в `tools/expert-widget-harness.html` + совпадение
  «золотых чисел» из спеки.
