## 3. Контракт кода (кратко; полный — §6 контекста + widgets/README)

`window.EXPERT_WIDGETS[id] = function(box){…}`; vanilla JS ES2017; Canvas 2D / inline SVG;
тёмная тема через CSS-переменные с фолбэками (`--txt, --mut, --acc2, --ok, --bad, --warn, --line, --mono`);
`mulberry32(seed)` для учебных сценариев; таймеры/rAF/resize снимаются в первых строках
(`box._expTimers / _expRaf / _expCleanup / _expRO`); адаптив от 360px; ноль внешних
зависимостей; без `alert/confirm/prompt`; артефакт — `box.dataset.artifact` + событие
`expert:artifact` (bubbles). Двигатели: `mount(box, instance, ctx)`, ctx = `glossary /
journal / telemetry / rng / lang / save-load` (предоставит диспатчер v16; в харнессе — заглушка).
60 FPS: анимации только `transform/opacity`, один rAF-луп на экран, `prefers-reduced-motion`.

## 6. Переиспользование (главное требование владельца)

Агенты пишут изолированный код — это главный риск схемы. Правила:

1. **До создания любой сущности** (компонент, хелпер, датасет, CSS-токен, генератор данных)
   проверь: `_registry.json` (widgets/engines/shared), общие слои `_shared-00/01/02`,
   существующие 48 виджетов (паттерны), каталог сущностей агента 05, инстансы в `content/data/`.
2. **Спека прямо говорит, чем переиспользовать** (эксперт задумывал переиспользование):
   двигатели для «механики», инстансы для «контента»; «ситуация-выбор» для диалоговых сцен;
   E4 для всех ритуалов; общий движок для ЖИ-4/6/15. Если спека отсылает к сущности —
   используй её, не пиши свою.
3. **Новая общая сущность** — только если используется ≥2 виджетами, и только в
   `_shared-XX`/`engines/` с записью в _registry (поле `usedBy`).
4. **Дубликат = дефект.** Архитектор (агент 05) проверяет партии на дубли; дубли вернутся
   на переделку.
5. Числа/данные: только из спек/уроков; константы треков — в `content/data/params_moex.json`
   / `params_life.json` (структура §7 реестра решений, создаёт их методолог/архитектор при
   необходимости; ты — читаешь).
