(~19 уроков на транш). Разбиение уроков по траншам — по порядку модулей:

имеют приоритет над старыми) → Python → вайбкодинг → FT → FAI → бонусы. Соответствие
«урок → транш» зафиксируй в головке каждого файла и в `content/06-mentor/atoms/README.md`
(создать: индекс траншей + статус-таблица 227 уроков ☐/☑).

**Правила извлечения:**
- Сырьё — тексты уроков `content/01-lesson-texts/*` (все паки). Атом — ВЫЖИМКА урока, не
  пересказ своими словами: тезисы (`theses`) — из заголовков/ключевых абзацев; `numbers` —
  только числа этого урока (со значениями); `terms` — термины урока; `trap` — ловушка/ошибка,
  которую урок разбирает; `analogy` — аналогия из текста (если нет — не выдумывать, поле
  `—`); `tasks` — задачи/вопросы «Проверь себя»; `socratic` — сократовские вопросы урока;
  `normalize` — правила нормализации (см. Приложение B); `difficulty` — по канону урока
  (easy/medium/hard из карты/урока).
- Блок строго машино-читаемый: `### <lesson_id>` + 9 полей списками с фиксированными
  префиксами (как в Приложении B; если формат B задаёт иные имена полей — следовать ему
  ТОЧНО). Проставь `source:` (файл+строка исходника) у `numbers` и `theses`.
- Дистракторы и реплики «Дежурный» — отдельными подразделами каждого атома, по форматам
  Приложения B/KR-карточек.
- **Валидатор `scripts/validate_atoms.py`** (создай): все 227 lesson_id покрыты (список id —
  из карты уроков; расхождения карте — отдельным отчётом), 9 полей распарсились, поля
  `numbers/theses/terms` непустые (пустое `analogy` — допустимо с `—`), 0 ошибок. Прогон —
  в конце каждого транша.

## 3. В.2 — Транш 2 W-E: мини-спеки ~21 «одиночного» урока (T-4.18 п.3)

Уроки без спек интерактивов (список в гэпах §В.2; первично ~26 М-нумерации минус закрытые
fable8 → актуально ~21: М1/М3/М5–М15/М17–М22/М26/М29/М31/М33–М37/М41/М43–М48 за вычетом
закрытых карточками fable8, П17/П18/П25/П28/П32/П33/П36/П38/П43/П46/П52).

**Файл результата: `content/02-interactives/w-e-tranche2-minispecs.md`.** По каждому уроку —
**решение из двух**: (а) **мини-спека** или (б) фиксация **«без интерактива»** с обоснованием.

- Мини-спека (сокращённый паспорт; образец тона — карточки `math-rewrite-widget-cards.md`
  и формат electives-specs, но короче): `id` (ключ виджета) · урок · тип (симулятор/тренажёр/
  карточки/калькулятор…) · цель (1 фраза «момент ага») · длительность 3–7 мин · **данные**
  (таблица/JSON-инлайн: параметры, ряды, пороги — только из текста урока) · **модель расчёта**
  (формула/логика в 3–6 строк) · **приёмка** (2–3 золотых числа) · «Проверь себя» (2 вопроса
  с «почему так кажется») · артефакт (что пишет в профиль).
- «Без интерактива» — только для уроков, где текст самодостаточен (рассуждение/история);
  фиксируется строкой в карте уроков (статус «—» с пометкой «решение T-4.18 п.3, <дата>»).
- Критерий выбора: у урока есть числа/механика → мини-спека; нет → фиксация. Цель —
  «0 ПУСТО» в DoD v16: у каждого «одиночного» урока либо интерактив, либо осознанная фиксация.
- Обнови карту уроков (§15 п.4 и строки уроков) и реестр интерактивов (новые позиции).
