## 6. Железные правила (нарушение = переделка)

1. **Переезд и улучшение — никогда одновременно** (§13.4-1). Фаза 1 не меняет логику;
   каждое улучшение — отдельный коммит с пометкой «фаза 2, пункт N».
2. **Один source of truth:** запрещены vite-копии; только алиасы/обёртки к content/ и engine/.
   Дубль файла = дефект сборки (ловится диф-прогоном).
3. **Правило одной правки за коммит** в engine/ (фаза 2); каждый коммит — строка в worklog.
4. **Линты обязательны:** `quiz_lint.py` 0 BLOCK; `lint-content.mjs` (пустые ru_gutter без
   skip, термины без ru_card, метрики без formula_ru/zones, валидаторы без why_card, сценарии
   без misconception/takeaway, числа против course-canon.json) — падение = нет деплоя.
5. **Golden-паритет живёт дольше Фазы 1** (§13.4-3): 225+39 уроков сверяются на каждом шаге.
6. TS — слоями (схемы → @ts-check → новый код); легаси не переписывать ради TS.
7. 60 FPS — бюджетом (§13.4-5): CI-проверка размера бандла на урок с волны W-A.
8. Дуальные режимы «Наблюдение/Обучение» (§12) — один data layer, два поведенческих слоя
   (`engine/live/modes/`), телеметрия `live.obs.*` / `live.edu.*`; ничего не дублировать.
