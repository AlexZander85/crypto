## 1. Факты кода v12.1, на которых строится Этап 3 (проверено)

### 1.1. Формула «Курс %» — дублировать ТОЧНО (ТЗ §12.1)
Из `renderProgressStats()` (22116):
```js
const courseCompletionPct = Math.round(
  ((doneLessons / totalLessons) * 0.40 +
   (doneTerms / totalTerms) * 0.20 +
   (passedTests / totalTests) * 0.25 +
   (capstonePassed ? 0.15 : (capstoneScore / 100) * 0.15)) * 100
);
```
где: `totalLessons = coreLessonList().length` и `doneLessons = coreLessonsDoneCount()` (функции 13956–13961: `LESSONS.filter(l => !l.phase || l.phase <= 5)` — **только core-уроки**); `totalTerms = TERMS.length` (4421: `TERMS_RAW.filter(Boolean)`); `doneTerms = Object.values(learned).filter(x=>x===1).length` (`learned` — 13873); `totalTests = 6` (константа!); `passedTests = Object.entries(phaseTestsDone).filter(([k,v])=>k!=='exam_capstone' && v>=80).length` (считает ключи `p0..p5`, `p8` и прочие ≥80, кроме капстоуна); `capstoneScore = phaseTestsDone['exam_capstone'] || 0`, `capstonePassed = capstoneScore >= 85`.
Все функции/переменные — глобальные: реплицировать дословно, в одном месте (функция `learnCoursePct()`), никаких «упрощений». Расхождение с вкладкой «Прогресс» = баг приёмки №1.

### 1.2. Две разные метрики (не перепутать)
- «Y из 213 уроков» — по **всем** урокам: `LESSONS.filter(l=>lessonsDone[l.id]===1).length / LESSONS.length`; пофазовые счётчики — как в `renderPhaseLessonsView` (26186–26188): `LESSONS.filter(l=>l.phase===ph)` → `doneCount/phaseLessons.length` (бейдж `#cur_phase_progress_badge`).
- «Курс X%» — по формуле §1.1 (core-уроки + термины + тесты + капстоун). Подписи в UI должны явно различать эти метрики.

### 1.3. Фазовое распределение и заголовки
- Уроки: 0:20, 1:12, 2:6, 3:6, 4:9, 5:7, 6:22 (16+4 vc+2 v4), 7:48, 8:56, 9:27 = 213. У всех уроков есть поле `phase` (0–9).
- Заголовки фаз — из `PHASES` (≈4440; `p` — номер, `title` — заголовок): «Фаза 0 · База и инфраструктура», «Фаза 1 · Research Pipeline…», … . ⚠️ Фаза 8 **вставляется в `PHASES` после фазы 4** (42762: `PHASES.splice(idx4+1, 0, psyPhase)`) — в «дорожной карте» она стоит не по номеру. Программа курса в плеере строится в **числовом порядке 0–9** (как вкладка уроков `switchPhaseLessons`), заголовки берутся из `PHASES` по `.p`; фазы, которых нет в `PHASES` (проверить 6/7/9), — заголовок-фолбэк «Фаза N» + счётчик уроков.
- Урок: `l.id, l.phase, l.num, l.title, l.lead, l.terms, l.blocks (concept.level1/level2, recap.points), l.timeEst, l.cognitiveLoad, l.mod`.

Публичный API: `LearnPlayer.openHome()`, `LearnPlayer.search(query)`, `LearnPlayer.openNote(noteId)`, `LearnPlayer.exportNotesMarkdown()`. Клавиатура: Esc — закрыть хаб/оверлей; Ctrl+K/⌘K — поиск (перехватывать только при открытом плеере/хабе, с `preventDefault`).

**Инварианты:** хаб и окно урока никогда не открыты одновременно (открытие урока из хаба закрывает хаб; закрытие плеера при `from:'home'` возвращает хаб); тема хаба = тема плеера (`data-lp-theme`, общие CSS-переменные `--lp-*`); все кликабельные элементы — `<button>`; фокус-трап — как в Этапе 1.

   ```js
   { id:'n'+ts, lessonId, stepIdx, quote: String(sel).trim().slice(0,500), note:'', ts }
   ```
   (заметку можно дополнить своим комментарием в панели); выделение снять; кнопка исчезает.
2. **Хранение:** LS `cn_learn_notes` = массив, лимит 500 заметок (старые вытесняются), дубликаты «тот же lessonId+quote» не создавать (обновлять ts).
3. **Панель «📝 Конспект»:** третья вкладка левой панели плеера («Шаги | Программа | Конспект») + раздел в Learn Home. Список, сгруппированный по урокам (заголовок — num + title урока), внутри — карточки «цитата (свернуть до 2 строк) · комментарий · дата»; клик по карточке → `LearnPlayer.open(lessonId, stepIdx)` (переход к шагу); поля: редактировать комментарий, удалить (с undo-тостом, без confirm()).
4. **«Скопировать всё»** (в панели и в Learn Home): собрать валидный markdown в буфер (`navigator.clipboard.writeText` с фолбэком `document.execCommand`):
   ```markdown
   # Конспект — КриптоНавигатор
   ## 4.2 Основа технического анализа (Фаза 4)
   > «цитата…»
   — комментарий
   ```
5. **Самопроверка (ТЗ §12.10.4):** выделение в шаге → кнопка → заметка; перезагрузка → заметка на месте; клик — переход к тому шагу; «Скопировать всё» — вставленный текст валиден (заголовки, цитаты, пустые строки).

### P7. Недавние уроки
1. При каждом `LearnPlayer.open(id)` — обновить `cn_learn_recent`: удалить прежнее вхождение этого lessonId, затем `unshift({lessonId, ts})`, обрезать до 5. ## 9. Риски и краевые случаи (фиксировать в отчёте)

| Риск | Митигация |
|---|---|
| Дрейф формулы «Курс %» | дословная реплика §1.1 + калибровка P0.3 + smoke + приёмка №1 |
| Две метрики («213 уроков» vs core-«Курс %») путают | явные подписи (§1.2); tooltip «как считает вкладка Прогресс» |
| `PHASES`-порядок (8 после 4) vs числовой | программа — числовой 0–9, заголовки из `PHASES` по `.p` (§1.3) |
| `totalTests=6` — константа при 7+ слотах | так считает приложение — реплицировать как есть; в отчёт (не «чинить») |
| Ctrl+K конфликтует с браузером | ловить только при открытом плеере/хабе, `preventDefault` |
| Выделение в виджетах/`pre code` | фильтр целей: input/textarea/canvas/`pre code` исключены |
| Квота localStorage (заметки) | лимит 500, цитата ≤500 символов |
| Хеш-роутер и поиск | переход из поиска использует штатный `open(id, idx)` Этапа 1 — роутер ставит хеш сам |
| Панель на мобильных | выдвижная панель (§4 P3.1), чипы не вытесняют навигацию (проверка 360px) |
| Живой sync хаба при смене прогресса | хаб перерисовывается при каждом `open()`; закрытие плеера при `from:'home'` возвращает хаб — данные свежие |
| `lessonsDone`-уроки без фазы | по факту у всех 213 есть `phase` (§1.3); если найдётся урок без фазы — он попадает только в «Y из 213», в программе не отображается; в отчёт |
